## Аннотация

Масса электрона `m_e c² = 510.99895000 ± 0.00000015 кэВ` (CODATA 2018) в Стандартной Модели — эмпирический ввод; вывода из более фундаментальных констант нет.

В настоящей работе `m_e` вычисляется численно из трёх вакуумных констант `{ε₀, μ₀, ℏ}` минимизацией Cosserat-функционала `E[n, u]` директорного поля `n: ℝ³ → S²` по трёхпараметрическому Hopf-анзацу с топологическим зарядом `Q_H = 1`. Все константы функционала фиксируются структурными тождествами из предыдущей работы [1]:

- шкала решётки `l₀⁴ = ℏ/(2π Z₀)`, где `Z₀ = √(μ₀/ε₀) ≈ 376.73 Ом`;
- базовая массовая шкала `M₀ c² = ℏc/l₀ ≈ 429.5068 эВ`;
- Cosserat-связь `μ_c = η = 2π`;
- эластичная анизотропия `K₃/K₁ − 1 = η`, с `K₁ = K₂ = 2`, `K₃ = 2(1 + 2π) ≈ 14.566`;
- Skyrme-член `c₄ = 1`.

Минимизация методом Нелдера–Мида на растянутой цилиндрической сетке `1024 × 2048` (дьядический бокс `L = 17 × 33 l₀`) даёт:

> `m_e^bare c² = 446.279 кэВ`

Это значение — **затравочная** масса электрона в Cosserat-вакууме: прямой выход затравочного функционала `E[n, u]`. Безразмерный минимум `Ẽ_min = E_min/M₀c² ≈ 1039` укладывается в дьядическую форму `m_e/M₀ = x² + x/2 − 1` с единственным масштабом `x = α⁻¹/4`: при затравочном `α_bare⁻¹ = 128` (`x = 32`) она даёт `1024 + 16 − 1 = 1039`, при физическом `α(0)⁻¹ = 137` (`x = 34.26`) — `1189.8`, то есть `m_e^phys ≈ 511 кэВ`. Тот же сдвиг масштаба `x`, что переводит затравочную `α` в измеренную, переводит и затравочную массу в физическую (§7.2–7.3). Дьядическая форма приводится как численное наблюдение, а не как вывод.

Топология сохраняется: `|Q_H| = 1` до `~4·10⁻⁵`; знак `−1` соответствует электрону.

## 1. Введение

### 1.1. Масса электрона в Стандартной Модели

`m_e c² = 510.99895000 ± 0.00000015 кэВ` входит в Стандартную Модель как эмпирический параметр. Юкавская связь `y_e ≈ 2.94 × 10⁻⁶` фиксируется этим значением; её малость относительно юкавы топ-кварка (`y_t ≈ 1`) не имеет независимого объяснения.

Попытки вывести `m_e` из более фундаментальной структуры (Эддингтон 1924 [9], Wyler 1969 [10], Atiyah 2018 [12]) либо были нумерологическими, либо опирались на произвольные нормировочные выборы.

### 1.2. Cosserat-вакуумная гипотеза

В предыдущей работе [1] показано, что при четырёх структурных отождествлениях база СИ сводится к одной размерности (энергии), а электромагнитный и гравитационный сектора помещаются в единую Cosserat-среду. Функционал `E[n, u]` в этой среде допускает локализованные минимумы с целочисленным `Q_H ∈ π₃(S²) = ℤ`. Минимум `Q_H = −1` отождествляется с электроном.

В настоящей работе вычисляется масса этого минимума.

### 1.3. Подход

1. Строится Cosserat-функционал, все константы которого фиксируются тройкой `{ε₀, μ₀, ℏ}` (§3).
2. Проводится минимизация методом Нелдера–Мида по 3-парам Hopf-анзацу на сетке `1024 × 2048` (§§4–5).
3. Минимум переводится в единицы SI через `M₀ c² = ℏc/l₀` (§6).

Результат: **топологически защищённая оценка сверху** для затравочной массы электрона `m_e^bare c² ≤ 446.279 кэВ`. Это минимум функционала `E[n,u]` на многообразии канонических Hopf-конфигураций; 3-парам анзац выступает аналитическим регулятором, отсекающим нефизические сеточные моды коллапса (см. §4.3 о роли анзаца, §7.4 о статусе результата). Величина не сравнивается напрямую с физической (измеренной) массой `m_e` — вывод соотношения «затравочное → физическое» оставлен как открытое направление (§7).

## 2. Cosserat-функционал

Cosserat-среда характеризуется двумя независимыми полевыми переменными: микроротацией, описываемой директором `n(r) ∈ S²`, и трансляционным смещением `u(r) ∈ ℝ³`. Энергетический функционал разделяется на три блока:

```
E[n, u]  =  E_n[n]   +   E_u[u]   +   E_int[n, u]                       (2.1)
```

**Блок E_n — энергия директорного канала** (Frank–Oseen + Skyrme):
```
E_n[n] = ∫ d³r [
    (K₁/2) (∇·n)²                ← разворот (splay)        (Frank, 1958)
  + (K₂/2) (n·∇×n)²              ← кручение (twist)        (Frank, 1958)
  + (K₃/2) (n×∇×n)²              ← изгиб (bend)            (Frank, 1958)
  + (c₄/4) F_ij F^ij             ← Skyrme-стабилизатор     (Skyrme, 1961; Faddeev–Niemi, 1997)
]                                                                       (2.2)
```

где `F_ij ≡ n · (∂_i n × ∂_j n)` — антисимметричный 2-тензор плотности топологического (Хопф-Уайтхедова) тока; в индексной форме `F_ij F^ij = 2·Σ_{i<j} [n·(∂_i n × ∂_j n)]²`. Это в точности стабилизатор Фаддеева–Скирма [6, 7]; именно эта антисимметричная свёртка реализована в коде (см. `verifications/electron_mass_minimization/stretched_grid.py`, `compute_skyrme_stretched`) и обеспечивает топологическую защиту площади сечения вихревой трубки от локального схлопывания.

**Замечание об отсутствии массового члена директора.** В (2.2) сознательно не вводится потенциал ориентации `V(n) ∝ (1 − n_z)` («масса» для `n`). Faddeev–Niemi Hopfion в 3D стабилен в чистой комбинации Frank–Oseen + Skyrme без такого члена [7, 8]: баланс Деррика между `K_i` (`∝ λ`) и `c₄` (`∝ λ⁻¹`) фиксирует масштаб солитона, а полиномиальный спад хвостов даёт сходящийся энергетический интеграл. Численная сходимость по сетке (§6.4) это эмпирически подтверждает. Введение `V(n)` рассматривалось и отвергнуто как избыточное параметрическое расширение, не диктуемое тождествами §3.

**Блок E_u — энергия трансляционного канала** (упругость + массовый член Юкавы):
```
E_u[u] = ∫ d³r [ (μ/2) (∂u)² + (μ_c/2) u² ]                              (2.3)
```

**Блок E_int — тензорная Cosserat-связь каналов `n` и `u`.** Микроротация директорного поля порождает векторный спиновый ток `Π(n)`, который должен сворачиваться с макроскопическим вращением среды `∇×u` — антисимметричной (изгибной) частью градиента смещения. Корректная тензорная форма связи:
```
E_int[n, u] = ½ μ_c ∫ d³r | ∇×u − Π(n) |²                            (2.4)
```
где `Π(n)` — векторный «спиновый ток» директора (аналог соотношения Mermin–Ho в superfluid ³He-A [21]). Слева и справа в `∇×u − Π(n)` стоят векторы; квадрат — корректный скаляр. Эйлер–Лагранжево условие `δE/δu = 0` даёт **векторное** уравнение `μ_c·∇×(∇×u) = μ_c·∇×Π(n)`, которое в калибровке `∇·u = 0` сводится к `−μ_c·∇²u = μ_c·∇×Π(n)`.

Для аксиально-симметричного Hopf-анзаца (§4) поле `Π(n)` имеет выделенную азимутальную компоненту, пропорциональную полярному углу `f(n) = atan2(√(n₁²+n₂²), n_z)` директора от вакуумного направления (0 на бесконечности, π в центре узла), а отклик `u` редуцируется к единственной скалярной моде `ψ(r,z)`. После редукции и интегрирования (см. §5.5) векторное уравнение для `u` принимает вид экранированного скалярного Пуассона с источником `−2·f(n)`:
```
( ∇²_φ − μ_c ) ψ  =  −2·f(n)                                        (2.4')
```
где `∇²_φ` — векторный лапласиан в действии на азимутальную компоненту (явный вид с членом `−1/r²` приведён в (5.5)).

Здесь `n_∞ = ẑ` — граничное значение на бесконечности; `μ` — базовый упругий модуль (`μ ≡ 1` в нат. единицах); `μ_c` — Cosserat-связь (§3.3, фиксируется тождеством `μ_c = η = 2π`).

В численной реализации (§5.5) решается именно скалярная редукция (2.4'); это не упрощающее приближение, а *эквивалентная* запись полной тензорной связи (2.4) в классе осесимметричных конфигураций. Полно-полевая 3D-релаксация без аксиальной симметрии потребует работать с (2.4) напрямую — это вынесено в готовящуюся отдельную работу (см. §8).

## 3. Константы из `{ε₀, μ₀, ℏ}`

### 3.1. Шкала длины `l₀`

```
l₀⁴ = ℏ / (2π · Z₀),   Z₀ = √(μ₀/ε₀) ≈ 376.730 Ом         (3.1)
⇒ l₀ ≈ 4.5943 Å
```

### 3.2. Базовая шкала массы `M₀`

```
M₀ c² = ℏc / l₀ = (2π ℏ³ / (c⁵ ε₀))^(1/4) c²              (3.2)
M₀ c² ≈ 429.5068 эВ
```

### 3.3. Cosserat-связь `μ_c`

```
μ_c = η = 2π                                              (3.3)
```

Безразмерная константа `η` есть прямое алгебраическое следствие определения шкалы `l₀` (3.1), а не свободный параметр функционала. Строгая, однозначная форма тождества получается сворачиванием фундаментальных констант в безразмерную комбинацию и подстановкой `l₀⁴ = ε₀ℏc/(2π)`:

```
η  =  ℏc·ε₀ / l₀⁴  =  ℏc·ε₀ / (ε₀ℏc/2π)  =  2π            (3.3a)
```

(`μ ≡ 1/ε₀` — постулат P2 из [1], так что `ℏc·ε₀ = ℏc/μ`.) Множитель `2π` здесь — буквально тот же, что стоит в определении `l₀⁴ = ℏ/(2π·Z₀)`: тождество `η = 2π` есть переписанное определение `l₀`. Геометрически этот `2π` отвечает телесному углу сферы-мишени `S²` (периоду `U(1)`-фазы директора).

**Физический смысл.** В натуральных единицах среды (`l₀ ≡ 1`, в которых записано каноническое тождество) `η` читается как отношение двух энергий одной ячейки — квантовой энергии вращения к упругой:

```
η  =  ℏω_gyro / (K · l₀)              (при l₀ = 1)         (3.3b)
```

- **Числитель** `ℏω_gyro` — квант минимальной энергии «гироскопа» размера `l₀`. Из квантования момента импульса ячейки (`I ~ M₀·l₀²`, `L ~ ℏ`): `ω_gyro = ℏ/(M₀·l₀²) = c/l₀` (через `M₀·l₀ = ℏ/c`), откуда `ℏω_gyro = ℏc/l₀ = M₀c² ≈ 429.5 эВ`.
- **Знаменатель** `K · l₀` — упругая энергия ячейки. `K` — константа Франка с размерностью `[энергия/длина]`, `K = μ·l₀`. Плотность Франка `K|∇n|² ~ K/l₀²` на объёме `l₀³` даёт энергию ячейки `K·l₀` (именно `K·l₀`, а не `K·l₀³`, имеет размерность энергии).

Содержательно: квантовые нулевые колебания поля `n` и упругая жёсткость вакуумной Cosserat-среды одного порядка и отличаются ровно на `2π`.

> **Замечание о единицах.** Строгой записью, не зависящей от выбора единиц, является (3.3a). Энергетическое отношение (3.3b) точно при `l₀ = 1`, где степени `l₀` схлопываются; при явной `l₀`-зависимости числитель `ℏc/l₀` и знаменатель `μl₀²` дают `η = ℏc·ε₀ = 2π` лишь после фиксации `l₀ = 1`. Поэтому показатель степени при `K·l₀` в (3.3b) — вопрос натуральных единиц, а не самостоятельный физический выбор.

### 3.4. Эластичная анизотропия `K₃/K₁`

```
K₁ = K₂ = 2,    K₃ = K₁ · (1 + η) = 2 · (1 + 2π) ≈ 14.566    (3.4)
```

> **Замечание о численном значении.** В коде минимизации использовано усечённое `K₃ = 14.56` (вместо `14.566`); сдвиг `m_e^bare` от этого усечения составляет `< 0.1 %` — в пределах дьядического отклонения (§6.2).

### 3.5. Skyrme-стабилизатор `c₄`

```
c₄ = 1                                                     (3.5)
```

### 3.6. Резюме

Все пять параметров функционала {`K₁, K₂, K₃, μ_c, c₄`} = {`2, 2, 14.566, 2π, 1`} фиксируются `{ε₀, μ₀, ℏ}` через тождества (3.1)–(3.5).

## 4. Hopf-анзац

### 4.1. Топологический контекст

Гладкое поле `n: ℝ³ → S²` с `n(r → ∞) = ẑ` продолжается до `S³ → S²`. Такие отображения классифицируются `π₃(S²) = ℤ`; целочисленный лейбл — инвариант Хопфа `Q_H`. Для электронного отождествления релевантный минимум — `Q_H = −1`.

### 4.2. Трёхпараметрический анзац

```
n₁ = 8 r z w / P
n₂ = -4 r Y w / P
n₃ = (D - 4 r² w²) / P                                    (4.2)

где:
  Y = r² + z² - 1                в масштабированных координатах (r/R_r, z/R_z)
  D = 4 z² + Y²
  P = D + 4 r² w²
```

Три параметра: `R_r` (радиус кольца), `R_z` (высота кольца), `w` (амплитуда кручения). Анзац несёт `|Q_H| = 1` для любых положительных `(R_r, R_z, w)` и сводится к `n₃ = 1` на бесконечности. Знак `Q_H` задаётся ориентацией поля; для отождествления с электроном выбирается `Q_H = −1` (для позитрона `+1`). Численная реализация (§5) даёт `Q_H = −0.99996` (§6.2) согласно соглашению, использованному в коде.

Выбор именно Hopf-анзаца (4.2) не произволен. Конфигурация с `Q_H = −1` есть замкнутая вихревая трубка директора `n`; её поперечное сечение — диск, площадь которого в Cosserat-программе [1, §7] алгебраически отождествляется с электрическим зарядом, `e = π·(l₀/2)²` (круговая геометрия сечения радиуса `l₀/2`). Анзац тем самым фиксирует **заряд как геометрическую площадь сечения трубки**, выраженную через шкалу `l₀`. Три параметра `(R_r, R_z, w)` задают лишь форму трубки; при оптимизации `(R_r, R_z)` связаны — под пространственным растяжением они масштабируются совместно (Деррик-баланс, см. сопутствующую проверку `canonical_derrick`), тогда как `w` — безразмерная амплитуда кручения — масштабу длины не подчиняется.

### 4.3. Анзац как топологический регулятор

Хотя минимизация по 3-парам анзацу (4.2) даёт численно стабильный результат (§5–6), важно явно зафиксировать **роль анзаца** в этом построении.

Полно-полевая релаксация всего директорного поля `n: ℝ³ → S²` без ограничения параметризацией (4.2) сталкивается с известной для Faddeev-Skyrme моделей **дискретизационной патологией**: при анизотропии `K₃/K₁ = 1 + η ≈ 7.28` штраф за изгиб (член `K₃`) толкает поле в режим стягивания ядра к нити вдоль оси, что снижает дискретную энергию ниже физически осмысленного значения. Подтверждено в нашей серии тестов полно-полевой релаксации (`verifications/grid_diagnostics/`): на боксах от `17×33` до `60×120` и на однородных сетках без растяжения наблюдается монотонное сжатие радиуса кольца `R_ring` с `0.33 l₀` до `0.018 l₀` при сохранении топологического заряда `|Q_H| = 1`, сопровождаемое парадоксальным **падением** дискретного Skyrme-вклада `E_Sk` (физически должен расти как `λ` при сжатии в `λ` раз по Деррику).

Эта патология имеет понятную природу. В континуальном пределе теорема существования Lin-Yang [24] гарантирует наличие нетривиального минимума функционала Faddeev–Skyrme в подходящих Соболевских пространствах. Однако на конечной сетке Skyrme-член `c₄ F_ij F^ij` теряет способность строго сопротивляться коллапсу из-за усечения градиентов на масштабе шага сетки `Δx` (любая разность не превосходит `π/Δx`). Континуальный барьер `λ⁻¹` в энергии становится конечным; солитон стягивается к субсеточному размеру.

Серия наших численных экспериментов (`test2`–`test9` в репозитории) — с добавлением жёсткости полярного угла, эффективного Eringen-γ-члена, BPS-секстика `c₆(F·F)²`, и нелокального кулоновского самодействия с натуральным коэффициентом `α_bare = 1/128` — показала, что эти структурно мотивированные добавки на дискретной сетке **действуют как независимый аддитивный штрафной член**, а не как барьер: поле находит конфигурацию, минимизирующую новый член ОТДЕЛЬНО от основного канала коллапса, и затем продолжает прежний сценарий с тем же финальным `E_tot − E_extra ≈ 422 кэВ`. Подробности — в диагностических скриптах `verifications/grid_diagnostics/` (тесты 2–9).

В этой ситуации **3-параметрический Hopf-анзац** (4.2) выступает **аналитическим регулятором**: он ограничивает оптимизацию многообразием конфигураций с фиксированной канонической геометрией вихревой трубки радиуса `R_r ~ l₀` и тем самым отсекает нефизические сеточные моды коллапса. Полученное `m_e^bare c² = 446.279 кэВ` есть, строго говоря, **топологически защищённая оценка сверху** для энергии истинного континуального минимума, реализующая физически осмысленную геометрию замкнутой вихревой трубки с заданным целочисленным зарядом.

Подход «жёсткий анзац как регулятор» — стандартный в численной хопфионной физике [7, 8, 25]. Снятие этой регуляризации требует геометрической дискретизации топологического заряда в духе Berg–Lüscher [26], при которой `Q_H` вычисляется не через локальные градиенты, а через телесные углы на ячейках, что делает топологический сектор абсолютно непроницаемым для численного коллапса. Полно-полевая реализация в этом стиле составляет предмет отдельной готовящейся работы (см. §7.4, §8).

## 5. Численный метод

### 5.1. Сетка

Цилиндрическая сетка `(r_i, z_j)` размера `N_r × N_z = 1024 × 2048` со сгущением около `r ~ R_r` и `z ~ 0` (растяжение `β_r = 6.0`, `β_z = 3.0`). Размеры бокса: `L_r = 17 l₀`, `L_z = 33 l₀` (`L_z = 2·L_r − 1`; обоснование `L_r` — ниже). Двойная точность (`float64`) повсеместно.

Размер бокса **дьядический**: радиальный размер удерживает 16-ячеечную массовую оболочку вокруг ядра `2¹⁰` плюс центральную ячейку:

```
L_r = 2⁴ + 1 = 17,    L_z = 2⁵ + 1 = 2·L_r − 1 = 33
```

(`r` — радиальная координата от оси симметрии, односторонняя; `z` — осевая, двусторонняя через центр узла, поэтому вдвое длиннее.)

Бокс тем самым целиком содержит локализованное ядро конфигурации и даёт стабильное **затравочное** значение; дальнодействующие медленные хвосты поля в него не входят — их учёт есть отдельная задача перенормировки через самоэкранирование заряда (переход `bare → phys`, бег `α`, §7.3), вынесенная в отдельную работу.

Затравочная масса определена именно на этом домене: `m_e^bare` есть энергия узла, локализованного в дьядическом боксе `17 × 33`. Дьядический бокс, охватывающий ровно оба сектора узла (заряд + масса), и фиксирует, что именно понимается под «затравочным» срезом.

### 5.2. Оптимизатор

Минимизация выполняется через `scipy.optimize.minimize` методом Нелдера–Мида с `xatol = 1e-6`, `fatol = 1e-4` (кэВ). Выбор метода обусловлен следующими соображениями:

1. Энергетический ландшафт по `(R_r, R_z, w)` гладкий, но не выпуклый.
2. Топологическое ограничение `Q_H = 1` обеспечивается анзацем точно и не требует отдельного контроля.
3. Градиентные методы по полному полю (Adam, L-BFGS) на дискретной сетке вызывают дрейф `Q_H` от целочисленного значения.

### 5.3. Сходимость

```
R_r = 0.64082   (в единицах l₀)
R_z = 0.80729
w   = 0.70200                                             (5.1)
```

### 5.4. Граничные условия по z

Для производных по `z` используются ghost-cells, построенные по линейной экстраполяции:
```
padded[Nz+i] = (i+1) · tensor[Nz-1] − i · tensor[Nz-2]
```

Альтернативный выбор — периодические BC (через `torch.roll`) — для данной задачи некорректен: Hopf-поле не периодично в `z`, и периодическая склейка создаёт скачок на границах `z = ±L_z/2`. Этот скачок вносит вклад в изгибный (bend) член, растущий с уточнением сетки, и приводит к расходимости результата по разрешению. При линейной экстраполяции сходимость по сетке сохраняется (`< 1 эВ` при удвоении).

### 5.5. Вычисление `E_u`: исключение u-канала

Численно для каждого `n` находим оптимальную скалярную моду `ψ`, параметризующую отклик u-канала (см. ниже), из уравнения Эйлера–Лагранжа функционала (2.1)–(2.4) и подставляем обратно в энергию.

**Аксиально-симметричная параметризация.** Для Hopf-анзаца (§4) отклик u-канала удобно параметризовать одной скалярной функцией `ψ(r,z)` — азимутальной компонентой векторного потенциала: `u = ∇×(ψ·φ̂)`. Тогда смещение бездивергентно автоматически (`∇·u = 0`), а его меридиональные компоненты:
```
u_r = −∂ψ/∂z ,    u_z = ψ/r + ∂ψ/∂r ,    u_φ = 0                  (5.4)
```
Источник `Π(n)` из (2.4) в этой симметрии редуцируется к азимутальному вектору `Π(n) = f(n)·φ̂`, где `f(n) = atan2(√(n₁²+n₂²), n_z)` — полярный угол директора.

**Сведение к скалярному уравнению.** Векторное Эйлер–Лагранжево уравнение `δE/δu = 0` функционала (2.3)–(2.4) после редукции к одной моде `ψ` принимает вид экранированного скалярного Пуассона:
```
( ∂²_r + (1/r) ∂_r − 1/r² + ∂²_z − μ_c ) ψ  =  −2 f(n)             (5.5)
```
Член `−1/r²` есть прямое следствие действия **векторного** лапласиана на азимутальную компоненту в цилиндрических координатах (кривизна базисных векторов `φ̂`) — без него теряется тензорная интерпретация.

Экранирующая длина `l_c = 1/√μ_c ≈ 0.399 l₀` играет роль **массы Юкавы** для u-канала: смещение `u` экспоненциально подавляется на масштабе `l_c` за пределами области, где `n` отклонён от `n_∞`. Источник `−2·f(n)` геометричен и от `μ_c` не зависит — он отражает чистую топологию узла.

Замечание о методологии. Скаляр `ψ` — это именно одна мода векторного отклика, а не «функция тока вместо вектора»: исходный функционал (2.4) тензорный, и редукция к (5.5) есть его эквивалент в классе осесимметричных конфигураций (одна скалярная мода исчерпывает векторный отклик в этой симметрии). Полно-полевая 3D-релаксация без аксиальной симметрии должна работать с (2.4) напрямую; такая работа вынесена в готовящуюся отдельную публикацию (см. §8).

**Численное решение.** Уравнение (5.5) решается методом сопряжённых градиентов с диагональным предобуславливанием (PCG) на равномерной подсетке `512 × 1024` с границами `L_r^{(u)} = 6 l₀`, `L_z^{(u)} = 12 l₀`. Компактность подсетки оправдана экспоненциальным затуханием решения на масштабе `l_c ≪ L_r^{(u)}`. Источник `f` интерполируется со сгущённой сетки `n` на равномерную сетку `ψ` билинейно. На внешней границе `r = L_r^{(u)}` ставится условие Робена, согласованное с асимптотикой `1/r` экранированного решения; относительная невязка PCG доводится до `10⁻⁸`. С этим условием значение `E_u` устойчиво относительно измельчения PCG-подсетки — проверено на подсетках от `512 × 1024` до `2048 × 4096`.

**Сборка энергии.** Из найденного `ψ` восстанавливаются `(u_r, u_z)` по (5.4), затем тензор деформации в осесимметрии:
```
ε_rr = ∂u_r/∂r ,   ε_zz = ∂u_z/∂z ,   ε_φφ = u_r/r ,
ε_rz = ½ (∂u_r/∂z + ∂u_z/∂r)                                     (5.6)
```
и плотность упругой энергии:
```
E_u = ∫ ( ε_rr² + ε_zz² + ε_φφ² + 2 ε_rz² ) · 2π r dr dz         (5.7)
```
Эта величина и есть `E_u = 3.758 кэВ` из таблицы §6.3 — гравитационная самоэнергия u-канала, индуцированная присутствием EM-топологии `n`.

**Замечание о пределах.** В пределе `μ_c → 0` (l_c → ∞) уравнение (5.5) теряет экранирование, источник `−2f` сохраняется, и `E_u` расходится по UV как самоэнергия точечного заряда в классической электродинамике. В обратном пределе `μ_c → ∞` (l_c → 0) массовый член подавляет `u` к нулю быстрее, чем источник успевает его возбудить: `u ≈ 2f/μ_c → 0`, и `E_u → 0`. Каноническое значение `μ_c = 2π` (3.3) обеспечивает `l_c ≈ 0.4 l₀` — порядка `R_r` — режим, в котором u-канал даёт конечный, но небольшой вклад (`~0.8 %` массы; см. §6.3). Физически это означает, что **связь n↔u не может быть устранена обнулением μ_c** (это, напротив, приводит к расходимости E_u): источник от топологии `n` существует всегда, и `μ_c` регулирует только степень его локализации.

E_OF   (Frank–Oseen, K₁ + K₂ + K₃)        :  221.888 кэВ  (49.7 %)

При удвоении разрешения сетки значение `m_e^bare` сдвигается менее чем на `1 эВ` (`~2·10⁻⁶` от `m_e^bare`). Сходимость по сетке устойчива, как и сохранение топологического заряда (`|Q_H| = 1` до `~4·10⁻⁵`).

### 6.5. Анализ чувствительности

Из тождеств §3 следует скейлинг:

```
m_e c²  ∝  ℏ^(3/4) · ε₀^(−5/8) · μ₀^(−3/8) · Ẽ_min        (6.5)
```

Безразмерный минимум `Ẽ_min` зависит только от безразмерных параметров `(K_i, μ_c, c₄)` и инвариантен относительно перемасштабирования `{ε₀, μ₀, ℏ}`. Чувствительность к `+1 %` возмущениям каждой из входных констант:

```
δ(ε₀)/ε₀ = +1 %  →  δ(m_e c²) / m_e c² ≈ −0.625 %
δ(μ₀)/μ₀ = +1 %  →  δ(m_e c²) / m_e c² ≈ −0.375 %
δ(ℏ)/ℏ   = +1 %  →  δ(m_e c²) / m_e c² ≈ +0.750 %         (6.6)
```

## 7. Обсуждение

### 7.1. Затравочный характер результата

Полученное `m_e^bare = 446.279 кэВ` есть **затравочная** масса электрона — минимум затравочного Cosserat-функционала `E[n, u]` по 3-параметрическому Hopf-анзацу. Это прямой выход функционала: величина не калибруется ни под какой эталон. Она принадлежит затравочному (UV) срезу построения: та же тройка `{ε₀, μ₀, ℏ}`, что фиксирует константы функционала (§3), фиксирует и затравочную постоянную тонкой структуры `α_bare = 2⁻⁷ = 1/128` [1, §7]. Таким образом, `446.279 кэВ` — масса электрона, отвечающая `α_bare = 1/128`; её связь с физической массой (отвечающей измеренной `α(0) = 1/137`) рассматривается в §7.3.

### 7.2. Дьядическая форма безразмерного минимума

Безразмерный минимум функционала `Ẽ_min = E_min / M₀c² = 1039.05` с точностью `~5·10⁻⁵` совпадает с целым `1039`. Это целое укладывается в дьядическую форму

```
Ẽ_min  =  m_e/M₀  =  x² + x/2 − 1,        x ≡ α⁻¹/4          (7.1)
```

где `x = α⁻¹/4` — безразмерный параметр полинома. Тождество `m_e/M₀ = l₀/ƛ_C` (поскольку `M₀ l₀ = ℏ/c` и `m_e ƛ_C = ℏ/c` — обе массы лежат на гиперболе `m·l = ℏ/c`) даёт независимое геометрическое толкование самого `Ẽ_min`, а не переменной `x`. Для затравочного значения постоянной тонкой структуры `α_bare⁻¹ = 128 = 2⁷` [1] масштаб `x = 32 = 2⁵`, и

```
Ẽ_min  =  32² + 32/2 − 1  =  1024 + 16 − 1  =  1039          (7.2)
```

Три члена отвечают «площади + полупериметру + точке» редуцированного 2D-узла: `x² = 2¹⁰` (ядро), `x/2 = 2⁴` (массовая оболочка), `−1` (центр). Дьядическая форма (7.1) получена в отдельном анализе дьядической структуры программы; здесь она приводится как **численное наблюдение** — её прямой вывод из функционала `E[n, u]` не выполнен.

> **Замечание о масштабе.** Формула (7.1) — это **частный случай для вакуума**, а не универсальная зависимость для электрона в любом состоянии. Она выполняется ровно потому, что в вакуумной точке гиперболы `m·l = ℏ/c` **1 ячейка массы среды (`M₀`) тождественно равна 1 единице модельной (безразмерной) энергии**: это граничный случай «вакуумного» узла, где обе величины (`α_bare = 1/128` и `M₀ = ℏ/(l₀c)`) выведены из одних и тех же постоянных `{ε₀, μ₀, ℏ}`. На других точках гиперболы (Compton-предел `m_0_local = m_e`, `l_local = ƛ_C`, где «узел = одна ячейка»; промежуточные атомные шкалы) это равенство нарушается: 1 ячейка среды ≠ 1 безразмерная единица, и **тождество (7.1) в той же форме не выполняется**.

### 7.3. Связь с физической массой через бег `α`

Формула (7.1) — функция единственного масштаба `x = α⁻¹/4`. Затравочному срезу отвечает `α_bare⁻¹ = 128` (`x = 32`); физический электрон измеряется при `α(0)⁻¹ = 137.036` (`x = 34.259`). Та же формула (7.1) на физическом `x` даёт:

```
m_e^phys / M₀  =  34.259² + 34.259/2 − 1  =  1173.68 + 17.13 − 1  =  1189.81
m_e^phys c²    =  1189.81 · M₀c²  ≈  511.0 кэВ
```

— что совпадает со стандартной массой электрона `m_e = 510.999 кэВ`. Отношение двух срезов:

```
m_e^bare / m_e^phys  =  1039 / 1189.81  =  0.8732               (7.3)
```

Поскольку заряд линеен по `x` (`α⁻¹ = 4x`), а масса квадратична (`m_e/M₀ = x² + x/2 − 1`), в лидирующем порядке `m_e ∝ x² ∝ 1/α²`. Чистый квадрат `(x_bare/x_phys)² = (32/34.259)² = 0.8725` отличается от полного отношения (7.3) `0.8732` на `~0.09 %` — это расхождение целиком объясняется под-членами `+x/2 − 1` формулы (7.1). Иначе говоря, **один и тот же сдвиг `x: 32 → 34.259`** (эквивалентно — бег `α⁻¹: 128 → 137.036`) переводит и заряд, и массу из затравочных значений в физические.

Это приводится как **числовое наблюдение** (наряду с §7.2), а не как вывод: показатель `2`, происхождение под-членов `+x/2 − 1` и сам бег `α` из Cosserat-функционала в настоящей работе не установлены — их вывод составляет предмет отдельной готовящейся работы о дьядическом объединении заряда, массы и масштаба.

### 7.4. Природа полученного минимума: анзац-регуляризованная верхняя оценка

Полученное `m_e^bare c² = 446.279 кэВ` следует трактовать как **минимум функционала `E[n,u]` на топологическом многообразии канонических Hopf-конфигураций** (анзац (4.2)), а не как глобальный минимум в неограниченном функциональном пространстве `n: ℝ³ → S²`. Это различие существенно по двум причинам.

**Во-первых**, оно делает результат строгой **верхней оценкой** для истинного континуального минимума: любая дополнительная свобода в форме конфигурации может лишь снизить энергию. Это согласуется с теоремой существования Lin-Yang [24] для континуального Faddeev–Skyrme минимума.

**Во-вторых**, оно фиксирует **что именно мы вычисляем** — не «голую массу свободной частицы как глобальный минимум функционала», а энергию **канонически параметризованной** конфигурации с `Q_H = ±1`, отождествляемой с электроном в Cosserat-вакууме. 3-парам анзац (4.2) выступает аналитическим регулятором, отсекающим нефизические сеточные моды коллапса (см. §4.3).

**Численное обоснование роли регулятора.** Сопровождающая серия тестов полно-полевой L-BFGS релаксации (`verifications/grid_diagnostics/`, тесты 2–9) показывает:

- *Снятие анзаца* (полнополевой L-BFGS, тот же бокс `17×33`, та же сетка) понижает энергию до `~422 кэВ` (−5.4 % от 446). Это **не истинный минимум** функционала, а артефакт дискретизации: радиус кольца `R_ring` сжимается с канонических `0.33 l₀` до субсеточных значений `0.02–0.1 l₀` в зависимости от бокса/сетки, при этом `E_Sk` парадоксально *падает* (физически должна расти по Деррику).

- *Структурные добавки* — жёсткость полярного угла `K_e|∇θ|²`, эффективный Eringen γ |∇×Π|², BPS-секстик `c₆(F·F)²`, нелокальное кулоновское самодействие с `α_bare = 1/128` — **не предотвращают коллапс** на дискретной сетке. Каждая добавка функционирует как независимый аддитивный штрафной член: поле находит конфигурацию, минимизирующую новый член отдельно от основного канала коллапса, и затем продолжает прежний сценарий с тем же финальным `E_tot − E_extra ≈ 422 кэВ`. Физически это связано с УФ-катастрофой на сетке: барьеры, аналитически расходящиеся при `R → 0`, на конечной сетке усекаются масштабом `Δx`, превращая бесконечный барьер в конечный штрафной член.

- *Переход к однородной сетке* (тест 5c, `17×33`) усугубляет коллапс до `R_ring = 0.018 l₀` с `E_tot = 393 кэВ`: растянутая сетка с фокусировкой `β_r = 6` около `r ~ R_r ~ l₀` создаёт **дополнительную численную защиту** от субсеточного коллапса, давая плохое разрешение при малых `r`.

Таким образом, значение `446.28 кэВ` — не континуальный минимум, случайно совпавший с анзацем, а **физически осмысленная величина, полученная именно благодаря анзацу как регулятору**. Дискретная Faddeev–Skyrme теория без анзаца теряет минимум на любой конечной сетке (детали — в техническом приложении `grid_diagnostics/`).

**Путь к снятию регуляризации.** Переход к полно-полевой минимизации без анзаца требует двух ингредиентов:

1. **Геометрической дискретизации топологического заряда** в духе Berg–Lüscher [26]: вычисление `Q_H` через телесные углы на ячейках, а не через локальные градиенты — это делает топологический сектор абсолютно непроницаемым для численного коллапса (любая попытка изменить `Q_H` требует прохождения через дираковскую сингулярность на отдельной ячейке).

2. **Структурной донастройки функционала** — переход в BPS-режим через шестипорядковый член `c₆ (F·F)²` (Adam–Sanchez-Guillen– Wereszczynski [27, 28]), либо явный учёт нелокальной электромагнитной жёсткости. Наш предварительный анализ (тесты 6, 8, 9) показывает, что стандартные формы таких добавок без геометрической дискретизации неэффективны; структурно правильная формулировка остаётся открытым вопросом.

Реализация в этом стиле — предмет отдельной готовящейся работы. В настоящей работе мы фиксируем `m_e^bare c² ≤ 446.279 кэВ` как **топологически защищённую оценку сверху**, полученную с анзац-регуляризацией.

### 7.5. Положение в Cosserat-программе

Настоящая работа примыкает к традиции выведения фундаментальной физики из топологии непрерывной среды. Главными представителями этой линии являются программа **Г. Е. Воловика** по аналогии между superfluid ³He-A и Стандартной Моделью [19] и программа **Х. Кляйнерта** по многозначным полям, описывающим дефекты как калибровочные поля и гравитацию через торсию (Einstein–Cartan) [20]. Математический аппарат всех трёх программ существенно общий: Frank–Oseen-подобная эластичность для директорного поля на сфере (для ³He-A — l-вектор орбитальной части), топологические инварианты гомотопических классов отображений, хопфионы как стабильные конфигурации.

Принципиальное различие — в выборе субстрата. Воловик работает с конкретной квантовой средой (superfluid ³He-A при милликельвиновых температурах), Кляйнерт — с упругим континуумом с дислокациями и дисклинациями. Настоящая работа берёт в качестве среды сам физический вакуум: четыре отождествления параметров среды с фундаментальными константами `{ε₀, μ₀, ℏ, G}` (см. [1]) превращают абстрактный континуум в конкретную модель, из которой выводится численная затравочная масса электрона `m_e^bare c² = 446.279 кэВ` при нулевом числе свободных параметров.

Шире, эти программы используют родственный математический аппарат (Frank–Oseen-эластика для `S²`-поля, топологические инварианты, хопфионы). **Одна возможная гипотетическая объединяющая картина** — KTHNY-каскад топологического плавления (Костерлиц–Таулес–Гальперин–Нельсон–Янг [22, 23]): жёсткий кристалл (Кляйнертов «World Crystal»), промежуточная гексатическая фаза (жидкокристаллическая, Frank–Oseen), изотропная жидкость (близкая к superfluid ³He-A). В этой гипотетической картине настоящая работа располагалась бы в промежуточной фазе с частицами как топологическими дефектами. **Строгая проверка такой картины для физического вакуума** (включая численное соответствие функционала `E[n, u]` соответствующей KTHNY-фазе) **не выполнена и остаётся открытым направлением**; здесь это упомянуто только как один из возможных широких контекстов, не как утверждение программы.

## 8. Заключение

**Топологически защищённая верхняя оценка** для затравочной массы электрона `m_e^bare c² ≤ 446.279 кэВ` получена численно из тройки вакуумных констант `{ε₀, μ₀, ℏ}` минимизацией Cosserat-функционала по 3-параметрическому Hopf-анзацу на дьядическом боксе `L = 17 × 33 l₀`. Результат стабилен по сетке (`< 1 эВ` при удвоении разрешения) и инвариантен относительно перешкалирования сетки и кода (см. §6.4); топологический заряд сохранён (`|Q_H| = 1` до `~4·10⁻⁵`).

3-параметрический Hopf-анзац выступает **аналитическим регулятором**, фиксирующим каноническую геометрию вихревой трубки с `Q_H = ±1` и отсекающим нефизические сеточные моды коллапса, неизбежно возникающие в дискретной Faddeev–Skyrme модели при больших анизотропиях `K₃/K₁` (§4.3, §7.4). Подход «жёсткий анзац как УФ-регулятор» — стандартный в численной хопфионной физике [7, 8, 25] и не уменьшает значимость полученного числа как **физически осмысленной верхней оценки** для континуального минимума, существование которого гарантируется теоремой Lin-Yang [24].

Безразмерный минимум `Ẽ_min ≈ 1039` укладывается в дьядическую форму `m_e/M₀ = x² + x/2 − 1` с единственным масштабом `x = α⁻¹/4`: при затравочном `α_bare⁻¹ = 128` (`x = 32`) она даёт `1024 + 16 − 1 = 1039`. Та же форма при физическом `α(0)⁻¹ = 137` (`x = 34.26`) даёт `1189.8` — то есть `m_e^phys ≈ 511 кэВ`, совпадающее со стандартной массой `510.999 кэВ`. Тот же сдвиг масштаба `x`, что переводит затравочную `α` в измеренную, переводит и массу из затравочного значения в физическое (§7.2–7.3).

Дьядическая форма приводится как **численное наблюдение**, а не как вывод: её прямое получение из Cosserat-функционала `E[n, u]` — открытое направление будущей работы.

Полно-полевая релаксация без анзац-регуляризации — минимизация по всему директорному полю `n: ℝ³ → S²` с геометрической дискретизацией топологического заряда в духе Berg–Lüscher [26] и структурной донастройкой функционала (вероятно, через шестипорядковый BPS-член [27, 28] или явный нелокальный канал самодействия) — готовится к отдельной публикации. Серия наших диагностических тестов (`verifications/ grid_diagnostics/`, тесты 2–9) показывает, что **стандартные формы** структурных добавок (полярный градиент, эффективный Eringen-γ, локальные BPS-варианты, кулоновское самодействие с натуральным `α_bare`) **на текущей конечно-разностной дискретизации не предотвращают коллапс** — каждая функционирует как независимый аддитивный штрафной член из-за УФ-обрезки аналитических расходимостей шагом сетки. Этот результат сам по себе представляет интерес как количественная характеристика **известной численной патологии Faddeev–Skyrme моделей**.

## Приложение B. Функционал в безразмерной форме

В безразмерных переменных (`r̃ = r/l₀`) функционал §2 принимает вид:

```
Ẽ[n, u]  =  Ẽ_n[n]  +  Ẽ_u[u]  +  Ẽ_int[n, u]              (B.1)

Ẽ_n[n] = ∫ d³r̃ [
    (K̃₁/2) (∇̃·n)²
  + (K̃₂/2) (n·∇̃×n)²
  + (K̃₃/2) (n×∇̃×n)²
  + (c̃₄/4) F̃_ij F̃^ij           ,  F̃_ij = n·(∂̃_i n × ∂̃_j n)
]                                                          (B.2)

Ẽ_u[u] + Ẽ_int[n, u] = ½ μ̃_c ∫ d³r̃ | ∇̃×u − Π(n) |²        (B.3)

(в осесимметричной редукции — `Π(n) = f(n)·φ̂`,
`u = ∇̃×(ψ·φ̂)`, и (B.3) сводится к экранированному
скалярному Пуассону (5.5))                                (B.4)
```

с безразмерными коэффициентами `{K̃₁, K̃₂, K̃₃, μ̃_c, c̃₄} = {2, 2, 14.566, 2π, 1}` (§3).

Масса в физических единицах: `m_e^bare c² = M₀ c² · Ẽ_min`.
