## Аннотация

Масса электрона `m_e c² = 510.998950 ± 0.000015 кэВ` (CODATA 2018) в Стандартной Модели — эмпирический ввод; вывода из более фундаментальных констант нет.

В настоящей работе `m_e` вычисляется численно из трёх вакуумных констант `{ε₀, μ₀, ℏ}` минимизацией Cosserat-функционала `E[n, u]` директорного поля `n: ℝ³ → S²` по трёхпараметрическому Hopf-анзацу с топологическим зарядом `Q_H = 1`. Все константы функционала фиксируются структурными тождествами из предыдущей работы [1]:

- шкала решётки `l₀⁴ = ℏ/(2π Z₀)`, где `Z₀ = √(μ₀/ε₀) ≈ 376.73 Ом`;
- базовая массовая шкала `M₀ c² = ℏc/l₀ ≈ 429.5068 эВ`;
- Cosserat-связь `μ_c = η = 2π`;
- эластичная анизотропия `K₃/K₁ − 1 = η`, с `K₁ = K₂ = 2`, `K₃ = 2(1 + 2π) ≈ 14.566`;
- Skyrme-член `c₄ = 1`.

Минимизация методом Нелдера–Мида на растянутой цилиндрической сетке `1024 × 2048` (дьядический бокс `L = 17 × 33 l₀`) даёт:

> `m_e^bare c² = 446.279 кэВ`

Это значение — **затравочная** масса электрона в Cosserat-вакууме: прямой выход затравочного функционала `E[n, u]`. Безразмерный минимум `Ẽ_min = E_min/M₀c² ≈ 1039` укладывается в дьядическую форму `m_e/m₀ = x² + x/2 − 1` с единственным масштабом `x = α⁻¹/4`: при затравочном `α_bare⁻¹ = 128` (`x = 32`) она даёт `1024 + 16 − 1 = 1039`, при физическом `α(0)⁻¹ = 137` (`x = 34.26`) — `1189.8`, то есть `m_e^phys ≈ 511 кэВ`. Тот же сдвиг масштаба `x`, что переводит затравочную `α` в измеренную, переводит и затравочную массу в физическую (§7.2–7.3). Дьядическая форма приводится как численное наблюдение, а не как вывод.

Топология сохраняется: `|Q_H| = 1` до `~4·10⁻⁵`; знак `−1` соответствует электрону.

## 1. Введение

### 1.1. Масса электрона в Стандартной Модели

`m_e c² = 510.998950 ± 0.000015 кэВ` входит в Стандартную Модель как эмпирический параметр. Юкавская связь `y_e ≈ 2.94 × 10⁻⁶` фиксируется этим значением; её малость относительно юкавы топ-кварка (`y_t ≈ 1`) не имеет независимого объяснения.

Попытки вывести `m_e` из более фундаментальной структуры (Эддингтон 1924 [9], Wyler 1969 [10], Atiyah 2018 [12]) либо были нумерологическими, либо опирались на произвольные нормировочные выборы.

### 1.2. Cosserat-вакуумная гипотеза

В предыдущей работе [1] показано, что при четырёх структурных отождествлениях база СИ сводится к одной размерности (энергии), а электромагнитный и гравитационный сектора помещаются в единую Cosserat-среду. Функционал `E[n, u]` в этой среде допускает локализованные минимумы с целочисленным `Q_H ∈ π₃(S²) = ℤ`. Минимум `Q_H = −1` отождествляется с электроном.

В настоящей работе вычисляется масса этого минимума.

### 1.3. Подход

1. Строится Cosserat-функционал, все константы которого фиксируются тройкой `{ε₀, μ₀, ℏ}` (§3).
2. Проводится минимизация методом Нелдера–Мида по 3-парам Hopf-анзацу на сетке `1024 × 2048` (§§4–5).
3. Минимум переводится в единицы SI через `M₀ c² = ℏc/l₀` (§6).

Результат: затравочная масса электрона `m_e^bare c² = 446.279 кэВ`. Это прямой выход затравочного функционала `E[n, u]`; величина не сравнивается с физической (измеренной) массой `m_e` — вывод соотношения «затравочное → физическое» оставлен как открытое направление (§7).

## 2. Cosserat-функционал

Cosserat-среда характеризуется двумя независимыми полевыми переменными: микроротацией, описываемой директором `n(r) ∈ S²`, и трансляционным смещением `u(r) ∈ ℝ³`. Энергетический функционал разделяется на три блока:

```
E[n, u]  =  E_n[n]   +   E_u[u]   +   E_int[n, u]                       (2.1)
```

**Блок E_n — энергия директорного канала** (Frank–Oseen + Skyrme):
```
E_n[n] = ∫ d³r [
    (K₁/2) (∇·n)²                ← разворот (splay)        (Frank, 1958)
  + (K₂/2) (n·∇×n)²              ← кручение (twist)        (Frank, 1958)
  + (K₃/2) (n×∇×n)²              ← изгиб (bend)            (Frank, 1958)
  + (c₄/4) [(∇n)² ⊗ (∇n)²]       ← Skyrme-стабилизатор     (Skyrme, 1961)
]                                                                       (2.2)
```

**Блок E_u — энергия трансляционного канала** (упругость + массовый член Юкавы):
```
E_u[u] = ∫ d³r [ (μ/2) (∂u)² + (μ_c/2) u² ]                              (2.3)
```

**Блок E_int — линейная связь n→u** (геометрический источник от топологии директора):
```
E_int[n, u] = − ∫ d³r [ 2·f(n) · u ],     f(n) = atan2(√(n₁²+n₂²), n_z)  (2.4)
```

Здесь `n_∞ = ẑ` — граничное значение на бесконечности; `f(n)` — полярный угол директора от вакуумного направления (0 на бесконечности, π в центре узла); `μ` — упругий модуль (в нат. единицах `μ = 1`).

## 3. Константы из `{ε₀, μ₀, ℏ}`

### 3.1. Шкала длины `l₀`

```
l₀⁴ = ℏ / (2π · Z₀),   Z₀ = √(μ₀/ε₀) ≈ 376.730 Ом         (3.1)
⇒ l₀ ≈ 4.5943 Å
```

### 3.2. Базовая шкала массы `M₀`

```
M₀ c² = ℏc / l₀ = (2π ℏ³ / (c⁵ ε₀))^(1/4) c²              (3.2)
M₀ c² ≈ 429.5068 эВ
```

### 3.3. Cosserat-связь `μ_c`

```
μ_c = η = 2π                                              (3.3)
```

Безразмерная константа `η` определяется как **отношение собственной квантовой энергии одной ячейки среды к её упругой энергии**:

```
η  =  ℏω_gyro / (K · l₀³)
```

Каждый из множителей имеет прямой физический смысл.

**Числитель: `ℏω_gyro` — квант минимальной энергии гироскопа.**
Частота `ω_gyro` определяется из квантования момента импульса гироскопа размера `l₀`: момент инерции `I ~ m₀·l₀²`, угловой момент `L ~ ℏ`, откуда
```
ω_gyro = L/I = ℏ/(m₀·l₀²) = c/l₀
```
(использовано тождество `m₀·l₀ = ℏ/c`). Энергия одного кванта вращения:
```
ℏω_gyro = ℏc/l₀ = M₀c² ≈ 429.5 эВ
```

**Знаменатель: `K · l₀³` — упругая энергия одной ячейки.**
`K` — константа Франка с размерностью `[энергия/длина]`. Связь с базовым модулем сдвига: `K = μ · l₀`, где `μ ≡ 1/ε₀` (постулат P2 из [1]). Тогда `K · l₀³ = μ · l₀⁴` — энергия, запасённая при деформации поля `n` порядка единицы в объёме одной ячейки.

**Подстановка фундаментального масштаба длины** `l₀⁴ = ε₀ℏc/(2π)` (см. (3.1)) приводит к:

```
η  =  ℏc / (μ · l₀⁴)
   =  ℏc · ε₀ · (2π) / (ε₀·ℏc)
   =  2π
```

Это не свободный параметр, а алгебраическое следствие тройки `{ε₀, μ₀, ℏ}`. Физический смысл результата: для вакуумной Cosserat-среды квантовая «дрожь» поля `n` и упругая жёсткость среды одного порядка и отличаются ровно на множитель `2π`.

### 3.4. Эластичная анизотропия `K₃/K₁`

```
K₁ = K₂ = 2,    K₃ = K₁ · (1 + η) = 2 · (1 + 2π) ≈ 14.566    (3.4)
```

### 3.5. Skyrme-стабилизатор `c₄`

```
c₄ = 1                                                     (3.5)
```

### 3.6. Резюме

Все пять параметров функционала {`K₁, K₂, K₃, μ_c, c₄`} = {`2, 2, 14.566, 2π, 1`} фиксируются `{ε₀, μ₀, ℏ}` через тождества (3.1)–(3.5).

## 4. Hopf-анзац

### 4.1. Топологический контекст

Гладкое поле `n: ℝ³ → S²` с `n(r → ∞) = ẑ` продолжается до `S³ → S²`. Такие отображения классифицируются `π₃(S²) = ℤ`; целочисленный лейбл — инвариант Хопфа `Q_H`. Для электронного отождествления релевантный минимум — `Q_H = −1`.

### 4.2. Трёхпараметрический анзац

```
n₁ = 8 r z w / P
n₂ = -4 r Y w / P
n₃ = (D - 4 r² w²) / P                                    (4.2)

где:
  Y = r² + z² - 1                в масштабированных координатах (r/R_r, z/R_z)
  D = 4 z² + Y²
  P = D + 4 r² w²
```

Три параметра: `R_r` (радиус кольца), `R_z` (высота кольца), `w` (амплитуда кручения). Анзац несёт `|Q_H| = 1` для любых положительных `(R_r, R_z, w)` и сводится к `n₃ = 1` на бесконечности. Знак `Q_H` задаётся ориентацией поля; для отождествления с электроном выбирается `Q_H = −1` (для позитрона `+1`). Численная реализация (§5) даёт `Q_H = −0.99996` (§6.2) согласно соглашению, использованному в коде.

Выбор именно Hopf-анзаца (4.2) не произволен. Конфигурация с `Q_H = −1` есть замкнутая вихревая трубка директора `n`; её поперечное сечение — диск, площадь которого в Cosserat-программе [1, §7] алгебраически отождествляется с электрическим зарядом, `e = π·(l₀/2)²` (круговая геометрия сечения радиуса `l₀/2`). Анзац тем самым фиксирует **заряд как геометрическую площадь сечения трубки**, выраженную через шкалу `l₀`. Три параметра `(R_r, R_z, w)` задают лишь форму трубки; при оптимизации `(R_r, R_z)` связаны — под пространственным растяжением они co-масштабируются совместно (Деррик-баланс, см. сопутствующую проверку `canonical_derrick`), тогда как `w` — безразмерная амплитуда кручения — масштабу длины не подчиняется.

## 5. Численный метод

### 5.1. Сетка

Цилиндрическая сетка `(r_i, z_j)` размера `N_r × N_z = 1024 × 2048` со сгущением около `r ~ R_r` и `z ~ 0` (растяжение `β_r = 6.0`, `β_z = 3.0`). Размеры бокса: `L_r = 17 l₀`, `L_z = 33 l₀` (`L_z = 2·L_r − 1`; обоснование `L_r` — ниже). Двойная точность (`float64`) повсеместно.

Размер бокса выбран не произвольно: он отвечает суммарной протяжённости двух секторов узла. Поле заряда достигает `99.9 %` своей полной величины при `R_charge ≈ 7 l₀`; массовый сектор — описываемый дьядическим полиномом `m_e/m₀ = x² + x/2 − 1` (`x = α⁻¹/4`, см. §7.2) — локализован в пределах `R_mass ≈ 10 l₀`; оба радиуса подтверждены численно. Их сумма и задаёт радиальный размер бокса:

```
L_r = R_charge + R_mass = 10 + 7 = 17
```

Бокс тем самым целиком содержит локализованный кор конфигурации и даёт стабильное **затравочное** значение; дальнодействующие медленные хвосты поля в него не входят — их учёт есть отдельная задача перенормировки через самоэкранирование заряда (переход `bare → phys`, бег `α`, §7.3), вынесенная в отдельную работу.

Затравочная масса определена именно на этом домене: `m_e^bare` есть энергия узла, локализованного в дьядическом боксе `17 × 33`. Дьядический бокс, охватывающий ровно оба сектора узла (заряд + масса), и фиксирует, что именно понимается под «затравочным» срезом.

### 5.2. Оптимизатор

Минимизация выполняется через `scipy.optimize.minimize` методом Нелдера–Мида с `xatol = 1e-6`, `fatol = 1e-4` (кэВ). Выбор метода обусловлен следующими соображениями:

1. Энергетический ландшафт по `(R_r, R_z, w)` гладкий, но не выпуклый.
2. Топологическое ограничение `Q_H = 1` обеспечивается анзацем точно и не требует отдельного контроля.
3. Градиентные методы по полному полю (Adam, L-BFGS) на дискретной сетке вызывают дрейф `Q_H` от целочисленного значения.

### 5.3. Сходимость

```
R_r = 0.64082   (в единицах l₀)
R_z = 0.80729
w   = 0.70200                                             (5.1)
```

### 5.4. Граничные условия по z

Для производных по `z` используются ghost-cells, построенные по линейной экстраполяции:
```
padded[Nz+i] = (i+1) · tensor[Nz-1] − i · tensor[Nz-2]
```

Альтернативный выбор — периодические BC (через `torch.roll`) — для данной задачи некорректен: Hopf-поле не периодично в `z`, и периодическая склейка создаёт скачок на границах `z = ±L_z/2`. Этот скачок вносит вклад в bend-член, растущий с уточнением сетки, и приводит к расходимости результата по разрешению. При линейной экстраполяции сходимость по сетке сохраняется (`< 1 эВ` при удвоении).

### 5.5. Вычисление `E_u`: исключение u-канала

Численно мы решаем задачу честно: для каждого `n` находим оптимальное `u` из уравнения Эйлера–Лагранжа функционала (2.1)–(2.4) и подставляем обратно в энергию.

**Вывод уравнения.** Часть функционала, зависящая от `u`, есть `E_u[u] + E_int[n,u]`:
```
∫ d³r [ (μ/2)(∂u)² + (μ_c/2) u² − 2·f(n)·u ]                    (5.2)
```
с `μ = 1` в нат. единицах. Условие минимума `δ/δu = 0` даёт линейное уравнение
```
( ∇² − μ_c ) u  =  −2·f(n)                                       (5.3)
```
— экранированный Пуассон с длиной `l_c = 1/√μ_c ≈ 0.399 l₀`. Член `−μ_c` играет роль **массы Юкавы для u-канала**: смещение `u` экспоненциально подавляется на масштабе `l_c` за пределами области, где `n` отклонён от `n_∞`. Источник `−2·f(n)` геометричен и от `μ_c` не зависит — он отражает чистую топологию узла.

**Осесимметричное представление.** В цилиндрической геометрии вводится функция тока `ψ(r,z)`, обеспечивающая `∇·u = 0` автоматически:
```
u_r = −∂ψ/∂z ,    u_z = ψ/r + ∂ψ/∂r                              (5.4)
```
Подстановка (5.4) в (5.3) даёт скалярное уравнение для `ψ`:
```
( ∂²_r + (1/r) ∂_r − 1/r² + ∂²_z − μ_c ) ψ  =  −2 f               (5.5)
```
Член `−1/r²` появляется из кривизны цилиндрических базисных векторов при действии векторного лапласиана на азимутальную компоненту.

**Численное решение.** Уравнение (5.5) решается методом сопряжённых градиентов с диагональным предобуславливанием (PCG) на равномерной подсетке `512 × 1024` с границами `L_r^{(u)} = 6 l₀`, `L_z^{(u)} = 12 l₀`. Компактность подсетки оправдана экспоненциальным затуханием решения на масштабе `l_c ≪ L_r^{(u)}`. Источник `f` интерполируется со сгущённой сетки `n` на равномерную сетку `ψ` билинейно. На внешней границе `r = L_r^{(u)}` ставится условие Робена, согласованное с асимптотикой `1/r` экранированного решения; относительная невязка PCG доводится до `10⁻⁸`. С этим условием значение `E_u` устойчиво относительно измельчения PCG-подсетки — проверено на подсетках от `512 × 1024` до `2048 × 4096`.

**Сборка энергии.** Из найденного `ψ` восстанавливаются `(u_r, u_z)` по (5.4), затем тензор деформации в осесимметрии:
```
ε_rr = ∂u_r/∂r ,   ε_zz = ∂u_z/∂z ,   ε_φφ = u_r/r ,
ε_rz = ½ (∂u_r/∂z + ∂u_z/∂r)                                     (5.6)
```
и плотность упругой энергии:
```
E_u = ∫ ( ε_rr² + ε_zz² + ε_φφ² + 2 ε_rz² ) · 2π r dr dz         (5.7)
```
Эта величина и есть `E_u = 3.758 кэВ` из таблицы §6.3 — гравитационная самоэнергия u-канала, индуцированная присутствием EM-топологии `n`.

**Замечание о пределах.** В пределе `μ_c → 0` (l_c → ∞) уравнение (5.3) теряет экранирование, источник `−2f` сохраняется, и `E_u` расходится по UV как самоэнергия точечного заряда в классической электродинамике. В обратном пределе `μ_c → ∞` (l_c → 0) массовый член давит `u` к нулю быстрее, чем источник успевает его раскачать: `u ≈ 2f/μ_c → 0`, и `E_u → 0`. Каноническое значение `μ_c = 2π` (3.3) обеспечивает `l_c ≈ 0.4 l₀` — порядка `R_r` — режим, в котором u-канал даёт конечный, но небольшой вклад (`~0.8 %` массы; см. §6.3). Физически это означает, что **связь n↔u нельзя выключить нулём μ_c** (это, наоборот, разгоняет E_u до бесконечности): источник от топологии `n` существует всегда, и `μ_c` регулирует только степень его локализации.

## 6. Результаты

### 6.1. Предсказанная масса электрона

Минимум функционала даёт:

```
Ẽ_min       = 1039.05
2¹⁰ + 2⁴ − 1 = 1039
отклонение  = +5.0·10⁻⁵  (= +0.0049 %, или +21.7 эВ)        (6.2)
```

### 6.2. Сохранение топологического заряда

```
Q_H = −0.99996   (электрон, |Q_H| = 1 до ~4·10⁻⁵)            (6.3)
```

```
E_OF   (Frank–Oseen, K₁ + K₂ + K₃)        :  221.888 кэВ  (49.7 %)
E_Sk   (Skyrme-стабилизатор, c₄)           :  220.634 кэВ  (49.4 %)

─────────────────────────────────────────────────────────────────
Итого                                      :  446.279 кэВ  (100 %)   (6.4)
```

На дьядическом боксе члены Frank–Oseen и Skyrme несут почти равные доли (`49.7 %` и `49.4 %`) — стандартный баланс Деррика: Frank–Oseen скейлится как `λ`, Skyrme как `λ⁻¹` при равномерном перемасштабировании, и оба требуются с сопоставимой величиной для фиксации размера солитона [15]. Экранированная Cosserat-связь `E_u` вносит малую долю (`0.8 %`).

При удвоении разрешения сетки значение `m_e^bare` сдвигается менее чем на `1 эВ` (`~2·10⁻⁶` от `m_e^bare`). Сходимость по сетке устойчива, как и сохранение топологического заряда (`|Q_H| = 1` до `~4·10⁻⁵`).

### 6.5. Анализ чувствительности

Из тождеств §3 следует скейлинг:

```
m_e c²  ∝  ℏ^(3/4) · ε₀^(−5/8) · μ₀^(−3/8) · Ẽ_min        (6.5)
```

Безразмерный минимум `Ẽ_min` зависит только от безразмерных параметров `(K_i, μ_c, c₄)` и инвариантен относительно перемасштабирования `{ε₀, μ₀, ℏ}`. Чувствительность к `+1 %` возмущениям каждой из входных констант:

```
δ(ε₀)/ε₀ = +1 %  →  δ(m_e c²) / m_e c² ≈ −0.625 %
δ(μ₀)/μ₀ = +1 %  →  δ(m_e c²) / m_e c² ≈ −0.375 %
δ(ℏ)/ℏ   = +1 %  →  δ(m_e c²) / m_e c² ≈ +0.750 %         (6.6)
```

## 7. Обсуждение

### 7.1. Затравочный характер результата

Полученное `m_e^bare = 446.279 кэВ` есть **затравочная** масса электрона — минимум затравочного Cosserat-функционала `E[n, u]` по 3-параметрическому Hopf-анзацу. Это прямой выход функционала: величина не калибруется ни под какой эталон. Она принадлежит затравочному (UV) срезу построения: та же тройка `{ε₀, μ₀, ℏ}`, что фиксирует константы функционала (§3), фиксирует и затравочную постоянную тонкой структуры `α_bare = 2⁻⁷ = 1/128` [1, §7]. Таким образом, `446.279 кэВ` — масса электрона, отвечающая `α_bare = 1/128`; её связь с физической массой (отвечающей измеренной `α(0) = 1/137`) рассматривается в §7.3.

### 7.2. Дьядическая форма безразмерного минимума

Безразмерный минимум функционала `Ẽ_min = E_min / M₀c² = 1039.05` с точностью `~5·10⁻⁵` совпадает с целым `1039`. Это целое укладывается в дьядическую форму

```
Ẽ_min  =  m_e/m₀  =  x² + x/2 − 1,        x ≡ α⁻¹/4          (7.1)
```

где `x` — единственный геометрический масштаб (число Compton-длин в вакуумной ячейке, `x = l₀/ƛ_C`). Для затравочного значения постоянной тонкой структуры `α_bare⁻¹ = 128 = 2⁷` [1] масштаб `x = 32 = 2⁵`, и

```
Ẽ_min  =  32² + 32/2 − 1  =  1024 + 16 − 1  =  1039          (7.2)
```

Три члена отвечают «площади + полупериметру + точке» редуцированного 2D-узла: `x² = 2¹⁰` (кор), `x/2 = 2⁴` (массовый шелл), `−1` (центр). Дьядическая форма (7.1) получена в отдельном анализе дьядической структуры программы; здесь она приводится как **численное наблюдение** — её прямой вывод из функционала `E[n, u]` не выполнен.

### 7.3. Связь с физической массой через бег `α`

Формула (7.1) — функция единственного масштаба `x = α⁻¹/4`. Затравочному срезу отвечает `α_bare⁻¹ = 128` (`x = 32`); физический электрон измеряется при `α(0)⁻¹ = 137.036` (`x = 34.259`). Та же формула (7.1) на физическом `x` даёт:

```
m_e^phys / m₀  =  34.259² + 34.259/2 − 1  =  1173.68 + 17.13 − 1  =  1189.81
m_e^phys c²    =  1189.81 · M₀c²  ≈  511.0 кэВ
```

— что совпадает со стандартной массой электрона `m_e = 510.999 кэВ`. Отношение двух срезов:

```
m_e^bare / m_e^phys  =  1039 / 1189.81  =  0.8732               (7.3)
```

Поскольку заряд линеен по `x` (`α⁻¹ = 4x`), а масса квадратична (`m_e/m₀ = x² + x/2 − 1`), в лидирующем порядке `m_e ∝ x² ∝ 1/α²`. Чистый квадрат `(x_bare/x_phys)² = (32/34.259)² = 0.8725` отличается от полного отношения (7.3) `0.8732` на `~0.09 %` — это расхождение целиком объясняется под-членами `+x/2 − 1` формулы (7.1). Иначе говоря, **один и тот же сдвиг `x: 32 → 34.259`** (эквивалентно — бег `α⁻¹: 128 → 137.036`) переводит и заряд, и массу из затравочных значений в физические.

Это приводится как **числовое наблюдение** (наряду с §7.2), а не как вывод: показатель `2`, происхождение под-членов `+x/2 − 1` и сам бег `α` из Cosserat-функционала в настоящей работе не установлены — их вывод составляет предмет отдельной готовящейся работы о дьядическом объединении заряда, массы и масштаба.

### 7.4. Положение в Cosserat-программе

Настоящая работа примыкает к традиции выведения фундаментальной физики из топологии непрерывной среды. Главными представителями этой линии являются программа **Г. Е. Воловика** по аналогии между superfluid ³He-A и Стандартной Моделью [19] и программа **Х. Кляйнерта** по многозначным полям, описывающим дефекты как калибровочные поля и гравитацию через торсию (Einstein–Cartan) [20]. Математический аппарат всех трёх программ существенно общий: Frank–Oseen-подобная эластичность для директорного поля на сфере (для ³He-A — l-вектор орбитальной части), топологические инварианты гомотопических классов отображений, хопфионы как стабильные конфигурации.

Принципиальное различие — в выборе субстрата. Воловик работает с конкретной квантовой средой (superfluid ³He-A при милликельвиновых температурах), Кляйнерт — с упругим континуумом с дислокациями и дисклинациями. Настоящая работа берёт в качестве среды сам физический вакуум: четыре отождествления параметров среды с фундаментальными константами `{ε₀, μ₀, ℏ, G}` (см. [1]) превращают абстрактный континуум в конкретную модель, из которой выводится численная затравочная масса электрона `m_e^bare c² = 446.279 кэВ` при нулевом числе свободных параметров.

Шире, эти программы используют родственный математический аппарат (Frank–Oseen-эластика для `S²`-поля, топологические инварианты, хопфионы). **Одна возможная гипотетическая объединяющая картина** — KTHNY-каскад топологического плавления (Костерлиц–Таулес–Гальперин–Нельсон–Янг [22, 23]): жёсткий кристалл (Кляйнертов «World Crystal»), промежуточная гексатическая фаза (жидкокристаллическая, Frank–Oseen), изотропная жидкость (близкая к superfluid ³He-A). В этой гипотетической картине настоящая работа располагалась бы в промежуточной фазе с частицами как топологическими дефектами. **Строгая проверка такой картины для физического вакуума** (включая численное соответствие функционала `E[n, u]` соответствующей KTHNY-фазе) **не выполнена и остаётся открытым направлением**; здесь это упомянуто только как один из возможных широких контекстов, не как утверждение программы.

## 8. Заключение

**Затравочная** масса электрона `m_e^bare c² = 446.279 кэВ` получена численно из тройки вакуумных констант `{ε₀, μ₀, ℏ}` минимизацией Cosserat-функционала по 3-параметрическому Hopf-анзацу на дьядическом боксе `L = 17 × 33 l₀`. Результат стабилен по сетке (`< 1 эВ` при удвоении разрешения) и инвариантен относительно перешкалирования сетки и кода (см. §6.4); топологический заряд сохранён (`|Q_H| = 1` до `~4·10⁻⁵`).

Безразмерный минимум `Ẽ_min ≈ 1039` укладывается в дьядическую форму `m_e/m₀ = x² + x/2 − 1` с единственным масштабом `x = α⁻¹/4`: при затравочном `α_bare⁻¹ = 128` (`x = 32`) она даёт `1024 + 16 − 1 = 1039`. Та же форма при физическом `α(0)⁻¹ = 137` (`x = 34.26`) даёт `1189.8` — то есть `m_e^phys ≈ 511 кэВ`, совпадающее со стандартной массой `510.999 кэВ`. Тот же сдвиг масштаба `x`, что переводит затравочную `α` в измеренную, переводит и массу из затравочного значения в физическое (§7.2–7.3).

Дьядическая форма приводится как **численное наблюдение**, а не как вывод: её прямое получение из Cosserat-функционала `E[n, u]` — открытое направление будущей работы.

Полно-полевая релаксация — минимизация по всему директорному полю `n: ℝ³ → S²` без ограничения 3-параметрическим анзацем, требующая связать гравитационный `u`-канал с массовым членом функционала, — готовится к отдельной публикации.

```
E_total = 446.279 кэВ  (= m_e^bare;  Ẽ_min ≈ 2¹⁰+2⁴−1, см. §7.2)
```

Типичный запуск сходится за `~ 90` симплекс-итераций (`172` вычисления функции); время на стене на одной NVIDIA RTX 2070 — порядка `6` минут.

## Приложение B. Функционал в безразмерной форме

В безразмерных переменных (`r̃ = r/l₀`) функционал §2 принимает вид:

```
Ẽ[n, u]  =  Ẽ_n[n]  +  Ẽ_u[u]  +  Ẽ_int[n, u]              (B.1)

Ẽ_n[n] = ∫ d³r̃ [
    (K̃₁/2) (∇̃·n)²
  + (K̃₂/2) (n·∇̃×n)²
  + (K̃₃/2) (n×∇̃×n)²
  + (c̃₄/4) [(∇̃n)² ⊗ (∇̃n)²]
]                                                          (B.2)

Ẽ_u[u] = ∫ d³r̃ [ (1/2)(∂̃u)² + (μ̃_c/2) u² ]                (B.3)

Ẽ_int[n, u] = − ∫ d³r̃ [ 2·f(n) · u ]                       (B.4)
```

с безразмерными коэффициентами `{K̃₁, K̃₂, K̃₃, μ̃_c, c̃₄} = {2, 2, 14.566, 2π, 1}` (§3).

Масса в физических единицах: `m_e^bare c² = M₀ c² · Ẽ_min`.
