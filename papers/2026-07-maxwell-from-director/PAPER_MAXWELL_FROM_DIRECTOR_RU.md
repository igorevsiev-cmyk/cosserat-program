# Уравнения Максвелла как теоремы о поле директора `n: ℝ³·¹ → S²`

**Все четыре уравнения электромагнетизма выводятся из одного предположения: у каждой точки вакуума есть направление. Однородная пара — следствие двумерности сферы направлений; неоднородная пара — точное тождество, которое само вычисляет ток источника. Электромагнетизм не постулируется, а доказывается.**

## Аннотация

**Коротко, без формул.** Уравнения Максвелла — четыре уравнения, описывающие всё электричество, магнетизм и свет, — в стандартной физике принимаются как законы природы: они подтверждены экспериментом, но ниоткуда не выводятся. В этой работе показано: если предположить, что у каждой точки вакуума есть *направление* (единичная стрелка `n`, «директор» — как у молекул жидкого кристалла), то все четыре уравнения Максвелла перестают быть постулатами и становятся **математическими теоремами** — следствиями чистой геометрии поля стрелок. Два уравнения (отсутствие магнитных зарядов и закон Фарадея) следуют из одного факта: сфера направлений двумерна. Два других (закон Кулона–Гаусса и закон Ампера) следуют из школьного правила дифференцирования произведения — и, в отличие от стандартной теории, *сами вычисляют*, что такое электрический заряд и ток: это узлы и завихрения поля стрелок. Заряд при этом автоматически целочисленный — потому что нельзя намотать сферу на сферу «полтора раза». Утверждения проверены численно: тождество выполняется с точностью 0.0001% (предел точности вычислительной схемы).

**Теперь строго.** В Cosserat-программе [SI-reduction; electron-mass] физический вакуум моделируется микрополярным континуумом, ориентационный канал которого описывается полем единичного директора `n(x): ℝ³·¹ → S²`. Из директора строится антисимметричный тензор — пулбэк формы площади сферы:

```
F_μν ≡ n · (∂_μ n × ∂_ν n)
```

Для него доказываются два утверждения:

1. **Однородная пара** (`∇·B = 0`, закон Фарадея) — **тождество Бьянки**, выполняющееся для *любого* гладкого поля `n`. Причина чисто геометрическая: все производные `∂_μ n` лежат в двумерной касательной плоскости к сфере, а смешанное произведение трёх векторов двумерного пространства тождественно равно нулю. Однородные уравнения Максвелла — следствие `dim S² = 2`.

2. **Неоднородная пара** (`∇·E = ρ`, закон Ампера) — **точное тождество Лейбница**

   ```
   ∂_μ F^μν = n·(□n × ∂^ν n) + n·(∂^μ n × ∂_μ ∂^ν n) ≡ j^ν
   ```

   верное опять же для *любого* `n` и *определяющее* ток источника `j^ν`. Ток локализован на дефекте (спад `~1/r⁵` для тестовой конфигурации — инстантона Белавина–Полякова), интегрируется в топологический заряд (`∫ j⁰ d²x ∝ Q ∈ ℤ`) и не содержит сингулярностей. Независимый вывод через CP¹-формулировку (варьирование составного потенциала `A_μ` как вспомогательного поля, формализм Д'Адда и др., 1978) отождествляет ток с током заряженной материи и фиксирует константу связи с физическими полями энергетической нормировкой (член Скирма ≡ максвелловский `F²/4μ₀`): `g₀ = √(μ₀c₄)`.

Тождество Лейбница подтверждено численно на инстантоне Белавина–Полякова (сетка `512²`, конечные разности 4-го порядка): **невязка `0.0001%`** — предел точности схемы; на каждом радиусе `r = 0.7–7.8` профильная невязка `0.00%`. Для гармонического отображения первый член тока обнуляется аналитически и численно (`‖term1‖/‖term2‖ ≈ 2×10⁻⁶`).

Физическая картина: вдали от ядра дефекта (`r ≫ l₀`) ток исчезает и уравнения Максвелла — *точное* описание дальнего поля; внутри ядра доминируют нелинейные члены, обеспечивая конечность массы там, где линейная электродинамика расходится. Отношение двух членов тока `|term1|/|term2| ~ c₄/c₂` вносит масштаб среды в структуру тока внутри частицы и участвует в фиксации радиуса вихревой трубки `r_v ≈ l₀/2` — того самого, что в [SI-reduction §7] даёт затравочную постоянную тонкой структуры `α_bare = 1/128`.

Эпистемический статус честен: работа **не выводит новое число** — она доказывает, что известная структура (Максвелл) есть *теорема* о поле `n`, и точно локализует, где эта структура ломается (ядро дефекта) и чем заменяется (нелинейная динамика, дающая массу).

**Дополнение (проверка 2026-07-02, §6.2 и §9):** перекрёстная сверка `g₀ ↔ e` выполнена. Динамический заряд CP¹-кванта даёт точное `q_w² = ℏε₀c/8 = (π/4)·l₀⁴` и `α_w = 1/(32π) ≈ 1/100.5` — тот же закон «заряд² ∝ l₀⁴», что и геометрический маршрут (`α_bare = 1/128`); расхождение — ровно множитель `4/π ≈ 1.27` (открыт). Тождество Лейбница подтверждено и на каноническом **3D-хопфионе**: невязка падает как `dx⁴` (0.59% → 0.13% на сетках 192³→288³), впервые численно виден скирмовский вклад в ток `‖term1‖/‖term2‖ = 0.372`.

**Ключевые слова:** уравнения Максвелла, Cosserat-континуум, поле директора, CP¹ сигма-модель, тождество Бьянки, модель Фаддеева–Скирма, топологический заряд, эмерджентная электродинамика.

## Для читателя, впервые встречающего программу

Этот раздел — необязательный для специалиста, но статья написана так, чтобы её можно было читать **без** знакомства с предыдущими работами программы. Вот минимальный контекст.

### Что такое уравнения Максвелла

Четыре уравнения (1861–1865), из которых следует вся классическая теория электричества, магнетизма и света:

| Уравнение | Что говорит человеческим языком |
|---|---|
| `∇·B = 0` | Магнитных зарядов (монополей) не бывает: линии магнитного поля всегда замкнуты |
| `∇×E + ∂B/∂t = 0` | Меняющееся магнитное поле закручивает электрическое (закон Фарадея — принцип генератора) |
| `∇·E = ρ` | Источник электрического поля — электрический заряд (закон Кулона–Гаусса) |
| `∇×B − ∂E/∂t = j` | Ток и меняющееся электрическое поле закручивают магнитное (закон Ампера) |

Первая пара называется **однородной** (в ней нет источников — правая часть ноль), вторая — **неоднородной** (справа стоят заряд `ρ` и ток `j`). В стандартной физике все четыре — **постулаты**: они обобщают эксперимент, но ниоткуда не выводятся, и что такое `ρ` и `j` — теория не говорит, их вносят руками.

### Что предполагает программа

Одну вещь: вакуум — не пустота, а упругая среда особого типа (континуум Коссера, 1909), у каждой точки которой есть не только положение, но и **собственная ориентация** — как если бы пространство было заполнено крошечными связанными гироскопами. Ориентация точки — это единичный вектор `n` («директор», термин из физики жидких кристаллов). Три константы среды отождествляются с тремя измеренными константами вакуума: плотность — с магнитной постоянной `μ₀`, жёсткость — с обратной электрической постоянной `1/ε₀`, квант закрутки — с постоянной Планка `ℏ`. Из них строится собственный масштаб длины среды `l₀ ≈ 0.46 нм` [SI-reduction]. Больше для чтения этой статьи ничего из программы знать не нужно.

### Главное различие, на котором построена статья: закон vs тождество

- **Закон** — утверждение о природе, которое могло бы быть иным и проверяется опытом. `F = ma` — закон.
- **Тождество** — утверждение, верное автоматически, по построению. `(a+b)² = a² + 2ab + b²` — тождество; его бессмысленно «проверять экспериментом».

Центральное утверждение работы: уравнения Максвелла, которые 160 лет считались законами, при взгляде через поле `n` оказываются **тождествами** — они не могут не выполняться, если поле направлений существует. Физическое содержание при этом не исчезает, а переезжает в другое место (какое именно — §7.3).

### Что нужно из математики

Векторное произведение `a × b`, смешанное произведение `a·(b × c)` (= объём параллелепипеда на трёх векторах), частные производные и правило дифференцирования произведения (правило Лейбница). Оба доказательства статьи занимают по несколько строк и используют только это.

## Эпистемическая этикетка (читать первой)

Программа пользуется четырёхуровневой шкалой силы утверждения (введена в [gravity-second-channel]): **[1]** метафора → **[2]** изоморфизм (воспроизводит известное, но без нового числа) → **[3]** предсказание числа → **[4]** предсказание нового эффекта.

Настоящая работа — **уровень [2] в самом сильном его виде**: не «аналогия с Максвеллом», а два математических доказательства того, что уравнения Максвелла суть тождества для поля `n: ℝ³·¹ → S²`, плюс численная верификация на пределе точности схемы. Новых чисел здесь нет — и это нужно проговорить сразу, чтобы читатель не искал их. Ценность в другом:

- **уравнения перестают быть постулатами** — из четырёх уравнений Максвелла ноль остаётся аксиомами, если принято существование поля `n`;
- **заряд получает объяснение квантованности** — он топологический (целое число намоток сферы на сферу), целочисленность не постулируется;
- **точно локализована граница применимости** линейной электродинамики: ядро дефекта, где та же структура, что рождает Максвелла, даёт конечную массу вместо расходимости.

Два места, где работа смыкается с уровнем [3] (сами числа выводятся в [SI-reduction] и [electron-mass], здесь — структурная основа для них): топологическое квантование заряда и баланс членов тока, фиксирующий `r_v ≈ l₀/2` и, следовательно, `α_bare = 1/128`.

> **Историческая рамка.** Максвелл получил свои уравнения (1861–62) именно из механической модели эфира — но постулируя устройство среды *ad hoc*, под ответ. Здесь ход обратный и более жёсткий: постулируется только Cosserat-среда с ориентационным каналом (три константы `{ε₀, μ₀, ℏ}` [SI-reduction]), а уравнения Максвелла возникают как теоремы о её директорном поле — вместе с границей своей применимости.

## 1. Введение

### 1.1. Картина на пальцах

Представьте, что каждая точка пространства несёт маленькую стрелку `n` — направление, единичный вектор. Стрелки соседних точек упруго связаны: резко развернуть одну относительно соседей стоит энергии. Тогда:

- **Свет** — рябь согласованных поворотов стрелок, бегущая по среде (как волна по колосящемуся полю).
- **Электрон** — узел: конфигурация стрелок, которую невозможно «расчесать» до однородной никакой плавной деформацией. Узел нельзя развязать — поэтому электрон стабилен; узлы бывают только с целым числом «намоток» — поэтому заряд квантован.
- **Электрическое и магнитное поля** — две проекции одной величины: скорости и направления, с которыми стрелки поворачиваются от точки к точке.

Вопрос статьи: каким уравнениям обязана подчиняться такая «рябь стрелок»? Ответ: **в точности уравнениям Максвелла** — и не потому, что мы их туда заложили, а потому, что ничему другому она подчиняться не может. Это утверждение доказывается, а не иллюстрируется.

### 1.2. Место работы в программе

Cosserat- (микрополярный) континуум — упругая среда, каждая точка которой несёт, помимо смещения `u`, независимую ориентацию `n`. Гипотеза программы [SI-reduction]: физический вакуум — такая среда, а наблюдаемая физика — её деформации и топологические дефекты. Два канала деформации:

```
n-канал (директор n: ℝ³ → S²)  — ориентация  → электромагнетизм (эта работа)
u-канал (смещение u ∈ ℝ³)      — трансляция  → гравитация [gravity-second-channel]
```

Предыдущие работы программы установили: редукцию базы единиц SI к одной размерности и две алгебраические «гиперболы» среды [SI-reduction]; затравочную массу электрона `m_e^bare = 446.279 кэВ`, вычисленную минимизацией энергии узла без свободных параметров [electron-mass]; структуру гравитационного сектора [gravity-second-channel]. Во всех этих работах негласно предполагалось, что n-канал «отвечает за электромагнетизм». Настоящая работа закрывает этот долг: она доказывает, что **уравнения электромагнетизма — уравнения Максвелла — являются математическими следствиями существования директорного поля**, и указывает, чем они заменяются там, где перестают работать.

### 1.3. Что именно утверждается

Утверждения работы разного логического ранга, и их важно разделить сразу:

| Утверждение | Ранг | Где |
|---|---|---|
| Однородная пара Максвелла — тождество для любого гладкого `n` | **теорема** | §4 |
| Неоднородная пара — тождество Лейбница, определяющее ток `j^ν` | **теорема** | §5 |
| Ток `j^ν` локализован, бессингулярен, `∫j⁰ ∝ Q ∈ ℤ` | теорема + числ. проверка | §5.3 |
| CP¹-вывод: ток = заряженная материя, `g₀ = √(μ₀c₄)`, `α_w = 1/(32π)` | стандартная процедура + идентификация | §6 |
| Максвелл — точный предел дальней зоны; в ядре — нелинейная динамика | следствие | §7 |
| Баланс членов тока → `r_v ≈ l₀/2` → `α_bare = 1/128` | мост к [SI-reduction §7] | §8 |

Первые две строки — центр работы. Подчеркнём их особый статус: они не зависят ни от энергетики среды, ни от уравнений движения, ни даже от того, верна ли Cosserat-интерпретация вакуума в целом. Это факты дифференциальной геометрии — они верны для любого поля направлений, где бы оно ни жило: в вакууме, в жидком кристалле, в ферромагнетике. Cosserat-среда нужна для третьего шага — идентификации `F_μν` с физическими `E`, `B` и коэффициентов с модулями среды.

### 1.4. Соотношение с известным

Составной тензор `F_μν = n·(∂_μn × ∂_νn)` и его связь с топологическим зарядом — классика теории сигма-моделей (Белавин–Поляков 1975; Фаддеев 1975; Д'Адда, Ди Веккья, Люшер 1978; учебный обзор — Раджараман 1982). Вклад настоящей работы не в изобретении этих объектов, а в трёх вещах:

1. **сборка полного вывода всех четырёх уравнений** в одной рамке, с явным разделением «геометрия (Бьянки)» / «тождество Лейбница (источник)»;
2. **бессингулярная форма тока** — через сам вектор `n`, а не через комплексную координату `z`, у которой есть координатная особенность (как у полюса на географической карте). Именно бессингулярная форма проходит численную проверку с точностью 0.0001%, тогда как «красивые» формы из учебников дают на практике невязки 40–86% (§5.4 — методологический урок);
3. **физическая идентификация** в Cosserat-среде: константа связи `g₀` из модулей среды, заряд как площадь сечения дефекта, граница применимости как ядро частицы.

## 2. Среда и поле директора

### 2.1. Постулаты (рекап [SI-reduction])

Три параметра упругой среды отождествлены с тремя измеренными константами вакуума:

```
ρ    = μ₀       — плотность среды ↔ магнитная постоянная
μ_el = 1/ε₀     — модуль сдвига (жёсткость) ↔ обратная электрическая постоянная
ℏ               — квант действия микроповоротов ↔ постоянная Планка
```

Первое следствие — скорость поперечной упругой волны такой среды `c = √(μ_el/ρ) = 1/√(ε₀μ₀)` совпадает со скоростью света: это то самое совпадение, из которого Максвелл в 1862 г. заключил, что свет — электромагнитная волна. Второе — из трёх констант строится единственный масштаб длины, `l₀⁴ = ε₀ℏc/(2π)`, `l₀ ≈ 0.46 нм` — «шаг структуры» среды. Он понадобится в §7–8.

Ориентация точки среды — единичный вектор `n(x, t)`. Множество всех возможных направлений трёхмерной стрелки — поверхность единичной сферы; её стандартное обозначение `S²`. Поле директора — отображение

```
n: ℝ³·¹ → S²,   |n|² = 1
```

(запись `ℝ³·¹` означает: аргумент — точка пространства-времени, три пространственные координаты плюс время).

Условие `|n| = 1` — не приближение, а определение: `n` — направление, у направления нет «длины». Из него одной строкой следует свойство, на котором построена вся статья. Продифференцируем `n·n = 1`:

```
∂_α(n·n) = 2 n·∂_α n = 0   ⟹   n ⊥ ∂_α n   для любого направления α
```

Наглядно: идёте вы по глобусу — ваша скорость всегда касательна к поверхности, «наружу» из сферы шагнуть нельзя. Так и здесь: как бы поле `n` ни менялось от точки к точке, вектор изменения `∂_α n` всегда лежит в **касательной плоскости** к сфере в точке `n`. А касательная плоскость к сфере **двумерна**. Это единственный геометрический факт, который понадобится для Теоремы 1.

### 2.2. Энергия поля (лагранжиан Фаддеева–Скирма)

Для полноты приведём энергетику среды — хотя, подчеркнём заранее, для теорем §4–5 она **не нужна**. Плотность энергии/действия ориентационного канала в длинноволновом пределе:

```
L[n] = (c₂/2)|∂_μ n|² + (c₄/4) F_μν F^μν                                    (1)
```

Первый член — обычная упругость: энергия растёт, когда соседние стрелки рассогласованы (коэффициент `c₂` — жёсткость). Второй — так называемый член Скирма (Скирм 1962; Фаддеев 1975): он включается только при очень быстрых поворотах поля и не даёт узлу схлопнуться в точку; его коэффициент `c₄` фиксируется условием `√(c₄/c₂) = l₀` — «узел не может быть меньше шага структуры среды». Тензор `F_μν` из второго члена определён в следующем разделе.

> **Замечание (член Скирма = энергия Максвелла).** Забегая вперёд: `F_μν` из второго члена — это и есть электромагнитное поле (§3.2), так что `(c₄/4)F_μνF^μν` — тот же инвариант, что лагранжиан Максвелла `−(1/4μ₀)F²_phys`. Скирмовская энергия узла — буквально **энергия его собственного электромагнитного поля** (для статического узла — магнитостатическая, `~∫B²`). Механизм стабилизации тогда читается физически: по Деррику упругий член при сжатии узла падает, скирмовский растёт — то есть *упругость среды хочет схлопнуть узел, а энергия его собственного ЭМ-поля не даёт себя сжать*. Столетняя проблема ЭМ-самоэнергии перевёрнута: у Абрагама–Лоренца самоэнергия разрывала классический электрон (требовались напряжения Пуанкаре, чтобы удержать), здесь она — стабилизатор, а держит среда. Количественно это не мелочь: в каноническом расчёте [electron-mass] скирмовский вклад `E_Sk = 220.6 кэВ` из `E_total = 446.3 кэВ` — **49.4%, почти точно половина затравочной массы электрона есть энергия его собственного ЭМ-поля** (реинкарнация программы «электромагнитной массы» Абрагама, но с конечным ответом). Совпадение коэффициентов (`c₄/4` против `g₀²/4μ₀`) при энергетической нормировке `g₀ = √(μ₀c₄)` точное по построению (§6.2); нетривиальная часть сверки переехала в заряд и закрыта с точностью до множителя `4/π` (§6.2, §9).

Порядок логики важен: `F_μν` определяется в §3 **до** и **независимо от** лагранжиана; теоремы §4–5 — тождества, верные для любого поля `n`, безотносительно к (1). Лагранжиан понадобится только в §6 (константа связи) и §8 (структура тока внутри частицы).

## 3. Тензор `F_μν`: сколько площади сферы заметает поле

### 3.1. Определение и смысл

```
F_μν ≡ n · (∂_μ n × ∂_ν n)                                                  (2)
```

Разберём конструкцию по шагам. Сдвинемся из точки `x` на шажок в направлении `μ` — стрелка повернётся на `∂_μ n`; сдвинемся в направлении `ν` — повернётся на `∂_ν n`. Оба вектора поворота лежат в касательной плоскости к сфере (§2.1). Их векторное произведение `∂_μ n × ∂_ν n` — вектор, перпендикулярный этой плоскости, то есть направленный вдоль `±n`, а его длина — площадь параллелограмма, натянутого на два поворота. Скалярное умножение на `n` извлекает эту площадь со знаком.

Итого: **`F_μν` — это ориентированная площадь на сфере направлений, которую «заметает» стрелка при сдвиге по паре направлений `(μ, ν)` в пространстве-времени.** На языке дифференциальной геометрии такая конструкция называется *пулбэком формы площади* `S²` (форма площади сферы на паре касательных векторов `a, b` равна `n·(a×b)` — ориентированная площадь параллелограмма, спроецированная на нормаль `n`); но для чтения статьи достаточно картинки с заметённой площадью. Там, где поле наматывает сферу быстро (ядро дефекта), `F` велико; где стрелки почти параллельны — `F` мало.

У «площади на сфере» есть решающее свойство: полная площадь сферы конечна (`4π`), и замкнутая поверхность в пространстве может накрыть её только целое число раз. Отсюда вырастет квантование заряда (§6.3).

### 3.2. Идентификация с E и B

Физические поля определяются из `F_μν` стандартным для теории поля способом, с одной размерной константой `g₀` (её значение — §6.2):

```
F_μν^phys = g₀ F_μν;    E_i = F_0i^phys,   B_i = −½ ε_ijk F_jk^phys          (3)
```

Наглядно: `F_μν` — антисимметричная матрица 4×4 (индексы: `0` — время, `1,2,3` — пространство), и её шесть независимых клеток — это и есть E и B:

```
        ν=0      ν=1      ν=2      ν=3
μ=0   ⎡  0      E_x      E_y      E_z  ⎤     строка времени → E
μ=1   ⎢ −E_x     0      −B_z      B_y  ⎥
μ=2   ⎢ −E_y    B_z       0      −B_x  ⎥     пространственный блок → B
μ=3   ⎣ −E_z   −B_y      B_x       0   ⎦
```

Словами: **электрическое поле** — площадь, заметаемая стрелкой при сдвиге «время + пространственное направление» (насколько быстро вращается стрелка во времени); **магнитное поле** — площадь при сдвиге по паре пространственных направлений (насколько закручено поле стрелок в пространстве). `E` и `B` — не две разные сущности, а две проекции одного объекта: деление зависит от выбора «строки времени», и при переходе в движущуюся систему отсчёта они перемешиваются — это просто поворот внутри одной таблицы.

### 3.3. Составной потенциал (для §6)

Направление стрелки можно закодировать одним комплексным числом `z = (n₁ + i n₂)/(1 + n₃)` — это стереографическая проекция, тот же приём, каким сферическую Землю рисуют на плоской карте. Через `z` из `n` строится **составной** калибровочный потенциал:

```
A_μ = Im(z̄ ∂_μ z)/(1 + |z|²),      ∂_μ A_ν − ∂_ν A_μ = ½ F_μν               (4)
```

Знакомый по электродинамике 4-потенциал `A_μ` здесь — не самостоятельное поле, а функция директора: производная от способа кодировки. Калибровочная свобода `U(1)` (возможность сдвинуть фазу `A_μ`, ничего не меняя в физике) — след произвола в выборе точки проекции на сфере.

Одно предупреждение, важное для дальнейшего: как любая плоская карта Земли, параметризация `z` имеет дефектную точку — «южный полюс» `n₃ = −1`, где `z → ∞` (как полюс на карте Меркатора, где меридианы сходятся). Все доказательства ниже ведутся в бессингулярных переменных `n`; кодировка (4) используется только там, где это безопасно (§6). Игнорирование этого предупреждения стоило двух неудачных версий численной проверки (§5.4).

## 4. Теорема 1: однородная пара — следствие двумерности сферы

> **Теорема 1.** Для любого гладкого поля `n: ℝ³·¹ → S²`
>
> ```
> ∂_λ F_μν + ∂_μ F_νλ + ∂_ν F_λμ = 0                                          (5)
> ```
>
> (в теории поля соотношение этого вида называется тождеством Бьянки).

**Доказательство.** Раскрываем `∂_λ F_μν` по правилу дифференцирования произведения (Лейбница):

```
∂_λ F_μν = ∂_λ n · (∂_μ n × ∂_ν n)
         + n · (∂_λ∂_μ n × ∂_ν n)
         + n · (∂_μ n × ∂_λ∂_ν n)
```

Складываем три таких выражения по циклу `(λ, μ, ν) → (μ, ν, λ) → (ν, λ, μ)`. Члены со вторыми производными сокращаются попарно: смешанные производные симметричны (`∂_λ∂_μ = ∂_μ∂_λ` — неважно, в каком порядке дифференцировать), а векторное произведение антисимметрично (меняет знак при перестановке сомножителей). Остаётся

```
Σ_cyc ∂_λ n · (∂_μ n × ∂_ν n)
```

— смешанное произведение трёх векторов `∂_λ n, ∂_μ n, ∂_ν n`, то есть объём параллелепипеда, натянутого на них. Но по §2.1 все три вектора лежат в **одной двумерной плоскости** — касательной плоскости к сфере. Параллелепипед, все рёбра которого прижаты к одной плоскости, плоский: его объём равен нулю. ∎

**Следствие (в компонентах 3+1).** Подстановка идентификации (3) в (5) даёт ровно однородную пару Максвелла:

```
∇·B = 0                     (нет магнитных монополей)
∇×E + ∂B/∂t = 0             (закон Фарадея)
```

### 4.1. Что здесь произошло

Однородная пара уравнений Максвелла оказалась **следствием одного числа: размерность сферы направлений равна 2**. Ни энергия среды, ни уравнения движения, ни какая-либо физика не использованы — только два факта: директор единичен (значит, его производные касательны к сфере) и сфера двумерна (значит, любые три касательных вектора лежат в одной плоскости и не образуют объёма).

Развернём, что это меняет. В стандартной электродинамике `∇·B = 0` и закон Фарадея постулируются — или, эквивалентно, постулируется существование 4-потенциала `A_μ`. Здесь потенциал не постулируется: он *автоматически существует* (формула (4)), потому что `F_μν` собран из отображения в сферу. Отсутствие магнитных монополей перестаёт быть загадочным эмпирическим фактом об отдельной сущности «магнитный заряд» и становится геометрическим свойством поля направлений: у заметаемой площади не бывает объёмных источников.

И обратная сторона, придающая утверждению фальсифицируемость: если бы внутреннее пространство ориентаций было трёхмерным (скажем, стрелка со свободной длиной, или `n ∈ S³`), тождество (5) сломалось бы — три касательных вектора перестали бы быть компланарными. **Однородные уравнения Максвелла — это экспериментальный тест на двумерность внутреннего пространства вакуума, и вакуум его проходит.** Обнаружение магнитного монополя опровергло бы Теорему 1 — и с ней всю конструкцию (§9).

## 5. Теорема 2: неоднородная пара — тождество, вычисляющее ток

Вторая пара Максвелла (`∇·E = ρ`, закон Ампера) — уравнения **с источником**: справа стоят заряд и ток. Стандартная электродинамика вводит `ρ` и `j` руками, как внешние данные. Здесь они не вводятся — они **вычисляются** из самого поля.

### 5.1. Точное тождество

> **Теорема 2.** Для любого гладкого поля `n: ℝ³·¹ → S²`
>
> ```
> ∂_μ F^μν = n·(□n × ∂^ν n) + n·(∂^μ n × ∂_μ∂^ν n)                            (6)
> ```
>
> (`□ = ∂_μ∂^μ` — волновой оператор, д'аламбертиан; по повторяющимся индексам — суммирование).

**Доказательство.** Раскрываем левую часть по правилу Лейбница — производная действует по очереди на каждый из трёх сомножителей `n·(∂^μn × ∂^νn)`:

```
∂_μ F^μν = (∂_μ n)·(∂^μ n × ∂^ν n)  +  n·(□n × ∂^ν n)  +  n·(∂^μ n × ∂_μ∂^ν n)
```

Первый член равен нулю тождественно — по той же причине, что и в Теореме 1: три вектора `∂_μ n, ∂^μ n, ∂^ν n` лежат в двумерной касательной плоскости, их смешанное произведение — объём плоского параллелепипеда. Остаются два члена. ∎

Правая часть (6) — это и есть ток. Дадим ему имя и обозначим слагаемые:

```
j^ν ≡ n·(□n × ∂^ν n) + n·(∂^μ n × ∂_μ∂^ν n)   ≡ term1 + term2               (7)
```

В компонентах 3+1 (с идентификацией (3)) уравнение (6) — в точности неоднородная пара Максвелла:

```
∇·E = ρ,        ∇×B − ∂E/∂t = j,        где ρ = g₀ j⁰,  j_i = g₀ j^i
```

Подчеркнём статус: (6) — **тождество**, а не уравнение движения. Оно выполняется для любой конфигурации `n`, включая никогда не реализующиеся в природе. Динамика (энергия среды) появится позже — она определит, *каким* будет ток у реальных конфигураций (§6, §8), но сама форма «`∂F = j`» от динамики не зависит. В стандартной теории форма уравнений и содержание источника — два независимых постулата; здесь форма — тождество, а источник — вычислимая функция поля.

### 5.2. Простейший случай: term1 = 0

Первый член тока содержит `□n` — «ускорение» поля. Для широкого класса конфигураций он выпадает. **Гармоническое отображение** — конфигурация, минимизирующая чистую упругую энергию `∫|∂n|²` (аналог мыльной плёнки: форма, которую поле принимает «само», без внешних сил); для таких полей `□n = −|∂n|² n`, то есть `□n` параллельно самому `n`. Тогда:

```
term1 = n·(□n × ∂^ν n) = −|∂n|² · n·(n × ∂^ν n) = 0        (так как n × n = 0)
```

и весь ток несёт второй член:

```
j^ν = n·(∂^μ n × ∂_μ∂^ν n)
```

Численная проверка (§5.4) подтверждает: `‖term1‖/‖term2‖ ≈ 2×10⁻⁶` на тестовой гармонической конфигурации. Случай, когда term1 включается (реальная частица со скирмовским членом), — §8.

### 5.3. Свойства тока

1. **Локализован на дефекте.** Ток собран из вторых производных поля и спадает быстро: для тестовой конфигурации (§5.4) — как `~1/r⁵`. Весь источник сосредоточен в ядре узла; вдали от него `j → 0`, и уравнения Максвелла становятся свободными. «Пустое пространство» электродинамики — это область, где стрелки поворачиваются плавно.

2. **Интегрируется в топологический заряд.** `∫ j⁰ d²x ∝ Q`, где `Q ∈ ℤ` — число намоток сферы на сферу (степень отображения). Целочисленность электрического заряда не постулируется — она топологическая (§6.3).

3. **Бессингулярен.** Форма (7) записана через сам вектор `n` — в ней нет дефектной точки «южного полюса» из §3.3. Это не косметика, а условие пригодности к вычислению: §5.4.

4. **Точен.** Тождество (6) — не разложение по малому параметру и не приближение; оно верно для любого гладкого `n` в каждой точке.

### 5.4. Численная верификация и методологический урок

Тождество проверено на **инстантоне Белавина–Полякова (BP)** — стандартной тестовой конфигурации теории сигма-моделей: это простейшая «текстура», наматывающая плоскость на сферу направлений ровно один раз (`Q = −1`). Её ценность для теста — известная точная формула: обе части (6) можно вычислить независимо и сравнить поточечно.

Параметры: масштаб `λ = 2`, сетка `512²`, бокс `L = 10`, конечные разности 4-го порядка; скрипт `code/verify_maxwell_v3.py`. Одна честная деталь: численный интеграл заряда по конечному боксу даёт `Q = −0.881`, а не `−1` — недостающие 12% сидят в медленно спадающем хвосте плотности заряда за границей бокса. На проверку самого тождества это не влияет: оно поточечное.

| Величина | Результат |
|---|---|
| Глобальная невязка `‖∂_μF^μν − j^ν‖/‖j^ν‖` | **0.0001%** (предел точности разностной схемы) |
| Профильная невязка по радиусам `r = 0.7–7.8` | 0.00% на каждом радиусе |
| `‖term1‖/‖term2‖` (гармоничность BP) | `2×10⁻⁶` |

История проверки поучительна и сознательно приведена ниже:

| Версия | Форма тока | Невязка | Диагноз |
|---|---|---|---|
| v1 | через комплексную координату `z` | 86% | координатная особенность «южного полюса» (`n₃ = −1`) |
| v2 | нётеровский `U(1)`-ток | 40% | не тот ток (совпадает с (7) только на связи `A = A[n]`) |
| **v3** | **тождество (7) через сам `n`** | **0.0001%** | ✓ |

Урок: «правильный» объект — не потенциал и не ток из красивой учебной формулировки, а бессингулярное тождество в исходных переменных поля. Невязки 40–86% первых версий — не численные ошибки, а неверно выбранные аналитические формы; падение невязки на шесть порядков в v3 подтверждает диагноз.

## 6. CP¹-вывод: почему ток — это заряженная материя, и чему равна константа связи

Тождество (6) даёт форму уравнений, но оставляет два вопроса. Первый: правая часть (7) — просто «то, что осталось от Лейбница»; почему её законно называть током *заряженной материи*? Второй: какова размерная константа `g₀` между геометрическим `F_μν` и физическими вольтами и теслами? На оба отвечает переформулировка через комплексную кодировку §3.3 — в литературе она называется CP¹-формулировкой (CP¹ — математическое имя сферы, описанной комплексной координатой).

### 6.1. Варьирование составного потенциала

В переменных `w = z/√(1+|z|²)` лагранжиан (1) переписывается точно (Д'Адда, Ди Веккья, Люшер 1978; Айхенхерр 1978):

```
L = 2c₂ |D_μ w|² + (c₄/4) F_μν F^μν,      D_μ w = (∂_μ − iA_μ) w             (8)
```

Читатель, знакомый с теорией поля, узнает форму (8) мгновенно: это **лагранжиан заряженного скалярного поля `w`, связанного с электромагнитным полем `A_μ`** — шаблон всей электродинамики материи. Разница с учебником одна: здесь `A_μ` не самостоятельное поле, а функция `n` (4).

Стандартный приём: временно рассматриваем `A_μ` как независимое вспомогательное поле и варьируем по нему. Получаем:

```
c₄ ∂_ν F^νμ = 2c₂ j^μ_CP¹,      j^μ_CP¹ = i(w̄ D^μ w − w \overline{D^μ w})    (9)
```

— неоднородные уравнения Максвелла, где справа — канонический ток заряженного скалярного поля. (Численный префактор в (9) зависит от соглашений `F = 2(∂A−∂A)` и нормировки `w`; для дальнейшего он не нужен — физическая нормировка заряда фиксируется ковариантной производной, §6.2.)

**Почему приём законен** (стандартное обоснование CP¹-моделей): уравнение (9), рассмотренное как уравнение на `A`, — алгебраическое, без производных от `A`; его решение в точности воспроизводит определение `A = A[z]` из (4). То есть варьирование по `A` не добавляет новой физики — оно возвращает собственное определение `A`. Аналогия: введя обозначение `s = a + b`, можно «варьировать по `s`» — получится `s = a + b` обратно; обозначение не стало от этого новой сущностью.

Ток `j^μ_CP¹` совпадает с током (7) из тождества Лейбница (на связи `A = A[n]`) — но записан через сингулярную кодировку и потому непригоден для вычислений (§5.4). Его ценность — интерпретация: **источник в уравнениях Максвелла ведёт себя в точности как заряженная материя, хотя никакой отдельной «материи» в теории нет — есть только поле стрелок.** Дуализм «поле–частица» здесь буквален: и «фотонная» часть (`F_μν`), и «зарядовая» (`j^μ`) собраны из одного `n`.

### 6.2. Константа связи и сверка с геометрическим зарядом (проверено 2026-07-02)

Нормировка `g₀` фиксируется **сопоставлением энергий**: скирмовский член лагранжиана (1) обязан совпасть с максвелловским. Записывая `F_μν = 2G_μν` (где `G_μν = ∂_μA_ν − ∂_νA_μ`, формула (4)) и `F_phys = γG` (то есть `A_phys = γA`), из равенства `(c₄/4)F² = C₄G² = (1/4μ₀)F_phys²` получаем:

```
γ = 2√(μ₀ c₄),      g₀ = γ/2 = √(μ₀ c₄)                                      (10)
```

Константа связи геометрии с вольтами и теслами **не свободна** — она выражается через жёсткость `c₄` и плотность среды `μ₀`. При каноническом значении `c₄ = 2ℏc` (конвенция кода, `c₄ = 1` в сим-единицах) член Скирма **тождественно** равен максвелловской плотности энергии — замечание §2.2 при этой нормировке становится точным равенством по построению.

> ⚠ **Исправление.** В ранней версии вывода константа записывалась как `g₀ = √(2c₂/(μ₀c₄))` — из сопоставления уравнения источника при дополнительном допущении «ток рескейлится той же константой, что и поле». Аудит 2026-07-02 показал, что эта форма размерно несовместима с энергетической нормировкой; корректна форма (10). Рескейлинг тока — отдельная константа, фиксируемая зарядом, а не полем.

**От `g₀` к заряду.** Минимальная связь в (8): `D_μ = ∂_μ − iA_μ = ∂_μ − i(A_phys,μ/γ)`. Сравнение с SI-формой `D = ∂ − i(q/ℏ)A_phys` даёт заряд кванта поля `w`:

```
q_w = ℏ/γ = ℏ/(2√(μ₀c₄))   ⟹   q_w² = ℏ²/(4μ₀c₄) = ℏε₀c/8 = (π/4)·l₀⁴
```

(последнее равенство — по структурному тождеству `l₀⁴ = ε₀ℏc/2π`). Соответствующая постоянная тонкой структуры получается **точной и универсальной** — ℏ и импеданс среды сокращаются:

```
α_w = q_w²/(4πε₀ℏc) = 1/(32π) ≈ 1/100.53
```

**Сверка двух маршрутов** (скрипт `code/verify_g0_and_identity_3d.py`, все тождества до 15 знаков):

| | динамический (CP¹, эта работа) | геометрический [SI-reduction §7] | согласие |
|---|---|---|---|
| закон | `q_w² = (π/4)·l₀⁴` | `e² = (π²/16)·l₀⁴` | **заряд² ∝ l₀⁴ — оба** ✓ |
| `α` | `1/(32π) = 1/100.5` | `1/128` | разрыв ровно `4/π ≈ 1.273` |
| эффективный радиус | `0.531·l₀` | `0.500·l₀` (плато `r_v = 0.498`) | 6% |

Структурный итог: **CP¹-динамика независимо воспроизводит «заряд = площадь ∝ l₀²»** — форму Гиперболы II — из одной лишь нормировки лагранжиана, без геометрических аргументов о вихревой трубке. Коэффициент же расходится ровно в `4/π`. Попутно — точное тождество `q_w² = e·l₀²` (заряд `w`-кванта есть среднее геометрическое площади дефекта и площади ячейки; записано как наблюдение, не вывод). Выяснение, какому объекту принадлежит элементарный заряд — кванту поля `w` или вихревой трубке дефекта, — и вывод множителя `4/π` — уточнённая форма открытого вопроса §9.

### 6.3. Заряд квантован — теорема, а не наблюдение

Интегральный заряд конфигурации:

```
Q = ∫ j⁰ d³x ∝ ∮ F₁₂ d²x = 4π × (число намоток n: S² → S²) ∈ 4πℤ
```

Смысл: обходя замкнутую поверхность вокруг дефекта, стрелка `n` пробегает всю сферу направлений какое-то число раз — и это число обязано быть **целым**: намотать сферу на сферу «полтора раза» нельзя, не разорвав поле. Электрический заряд квантован, потому что квантована намотка. Знак заряда — направление намотки (частица и античастица — противоположные закрутки).

Сравним со стандартной физикой: там квантование заряда — эмпирический факт без объяснения (либо аргумент Дирака, требующий существования магнитного монополя — которого никто не видел). Здесь — теорема о непрерывных отображениях, и монополь для неё не нужен; напротив, он запрещён Теоремой 1.

## 7. Физическая картина: где Максвелл точен и где кончается

### 7.1. Дальняя зона: точная электродинамика

Вдали от ядра дефекта (`r ≫ l₀`) стрелки поворачиваются плавно, ток (7) спадает быстрее любого кулоновского члена (`~1/r⁵` для тестовой конфигурации), и

```
∂_μ F^μν → 0
```

— свободные уравнения Максвелла. **В дальней зоне уравнения Максвелла — точное, а не приближённое описание**: поправки не «малы в меру чего-то», они сосредоточены в ядре и до дальней зоны просто не дотягиваются. Топологический заряд дефекта выступает точечным источником дальнего поля — это и есть привычный «точечный заряд» электростатики.

Фотон в этой картине — линейная волна поля `n` на однородном фоне: рябь стрелок без намотки (сектор `Q = 0`). Её безмассовость (свет не затухает и не диспергирует в вакууме) согласована с жёсткими экспериментальными пределами на массу фотона (`< 10⁻²⁷` эВ) и на зависимость скорости света от частоты (`Δc/c < 10⁻²⁰`, гамма-всплески Fermi GBM) — подробный дисперсионный анализ вынесен в отдельную работу программы.

### 7.2. Ядро: конечная масса вместо расходимости

У классической электродинамики есть столетняя болезнь: самоэнергия точечного заряда бесконечна (поле `~1/r²` при `r → 0` даёт расходящийся интеграл энергии). Здесь при `r ≲ l₀` картина другая: доминируют нелинейные члены поля `n`, и **та же структура, что в дальней зоне даёт Максвелла, в ядре даёт конечную энергию**. Численная минимизация полной энергии узла даёт конечную затравочную массу электрона `m_e^bare = 446.279 кэВ` [electron-mass]. Не два разных механизма («электродинамика» плюс пришитая к ней «регуляризация»), а один объект — поле `n`: его линейный хвост называется электромагнетизмом, его нелинейное ядро — массой частицы.

Иерархия описаний:

```
динамика поля n (фундаментальна везде)
   ⊃ уравнения Максвелла (точны в дальней зоне, r ≫ l₀)
   ⊃ кулоновское поле точечного заряда (ведущий член дальней зоны)
```

### 7.3. Почему это не «переупаковка»

Предвосхитим возражение: «раз уравнения — тождества, верные для любого `n`, они бессодержательны — вы ничего не предсказали, а лишь переписали известное». Ответ: содержание не исчезло, оно **переехало из уравнений в носителя**. Сравните списки постулатов:

| | Стандартная электродинамика | Эта работа |
|---|---|---|
| Форма 4 уравнений | постулат | тождество (теоремы 1–2) |
| Что такое `ρ`, `j` | внешние данные, вносятся руками | вычислимая функция поля (7) |
| Квантование заряда | необъяснённый факт | теорема о намотках (§6.3) |
| Константа связи | измеряется | формула (10) из модулей среды |
| Поведение при `r → 0` | расходимость | конечная масса (§7.2) |
| Магнитный монополь | допустим (даже желателен) | **запрещён** (§4.1) |

Фальсифицируемость сместилась туда же: сломать картину можно, показав, что реальный ток источника *не* локализован на дефектах, что заряд *не* топологичен, или что отклонения от Максвелла на малых масштабах имеют не ту структуру (§9).

### 7.4. Свободное поле как осциллятор среды: ток смещения = упругость

Дальняя зона (§7.1) — свободное поле `n` на однородном фоне. Здесь полезно прочитать выведенные уравнения в **механическом словаре** Cosserat-среды [SI-reduction], где параметры среды и компоненты поля отождествлены так:

```
1/ε₀ = G (модуль сдвига),   μ₀ = ρ (плотность)
E ↔ σ (напряжение),   D ↔ γ (деформация),   H ↔ v (скорость),   B ↔ ρv (плотность импульса)
```

(`D ↔ γ` следует из `[Q] ↔ [м²]`: тогда `[D] = Кл/м²` безразмерна — доля деформации; [SI-reduction §6].)

**Две плотности энергии — упругая и кинетическая.** Подстановка словаря в максвелловские плотности даёт тождественно:

```
электрическая   ½ε₀E²  =  ½σγ    — упругая (потенциальная)
магнитная       ½B²/μ₀ =  ½ρv²   — кинетическая
```

(проверка: `½ε₀E² = ½σ²/G = ½σγ` по Гуку `γ = σ/G`; `½B²/μ₀ = ½(ρv)²/ρ = ½ρv²`.) Электрический сектор среды упруг, магнитный — инерционен.

**Ток смещения = скорость упругой деформации.** В этом словаре максвелловский ток смещения читается как

```
J_смещ = ∂D/∂t  ↔  ∂γ/∂t      (скорость деформации)
```

— не перенос заряда, а **упругий отклик** среды: деформация, меняющаяся во времени. В ковариантной записи (§5) он — часть `∂_μ F^μν` (собственная вариация поля), а не источник `j^ν`; в вакууме `j = 0`, и поле сорсит само себя — это и есть волна.

**Свободное поле — гармонический осциллятор.** Две источник-свободные ротор-пары,

```
∇×H = ∂D/∂t ,     ∇×E = −∂B/∂t ,
```

связывают упругий сектор (`E`, `½σγ`) с инерционным (`B`, `½ρv²`): энергия переливается между ними. Исключение одной пары через другую даёт волновое уравнение с

```
ω² = (G/ρ) k² = c² k² ,     c = √(G/ρ)
```

— поперечную упругую волну среды, тождественную свету (то самое совпадение §2.1). **Фотон = свободное колебание среды между её упругостью (`E`) и инерцией (`B`)**, а ток смещения — «пружинный» член: без него нет обратного хода, а значит и волны. Именно его добавление Максвеллом (1861–62) замыкает осциллятор.

**Сосредоточенный предел = `LC`-контур.** Тот же осциллятор в цепи: конденсатор (упругость, копит `½σγ`) ↔ катушка (инерция, копит `½ρv²`), `ω = 1/√(LC)` — дискретный аналог `ω = ck`. Диссипация (ток проводимости узлов, §5–6) — вязкое трение: удельное сопротивление среды имеет единицы вязкости, `Ом·м = Па·с`.

**Статус.** Это **механическое прочтение** уже выведенных полевых уравнений (через словарь [SI-reduction]), а не новая теорема: уровень [2] (изоморфизм), нового числа нет. Оно проясняет физику свободного сектора — свет как упругая волна среды, ток смещения как её упругость — и согласуется с ядром (§7.2), где та же среда нелинейна и рождает массу.

## 8. Структура тока в ядре: мост к `r_v = l₀/2` и `α`

Этот раздел связывает статью с численными результатами программы; читателю, интересующемуся только выводом Максвелла, его можно пропустить.

Два слова контекста. **Хопфион** — трёхмерный узел поля `n` (замкнутая в кольцо закрутка, топологически неустранимая); в программе хопфион с `Q = −1` отождествляется с электроном. **Постоянная тонкой структуры** `α ≈ 1/137` — безразмерная мера силы электромагнитного взаимодействия; в [SI-reduction §7] её затравочное значение `α_bare = 1/128` выведено из геометрии узла: заряд = площадь сечения вихревой трубки радиуса `r_v = l₀/2`. Вопрос: откуда берётся сам радиус `r_v`? Частичный ответ даёт структура тока (7).

Уравнение движения поля `n` из лагранжиана (1) (с множителем Лагранжа при связи `|n| = 1`):

```
c₂ □n + c₄ ∂_μ[F^μρ (∂_ρ n × n)] = λ n                                       (11)
```

Без скирмовского члена (`c₄ = 0`) решения гармоничны, `□n ∥ n`, и term1 в токе (7) исчезает (§5.2). Но в реальном хопфионе `c₄ ≠ 0`: скирмовский член отклоняет `□n` от направления `n`, и term1 включается. Выражая его из (11):

```
term1 = n·(□n × ∂^ν n) = −(c₄/c₂) ∂^ν n · (n × ∂_μ[F^μρ(∂_ρ n × n)])
```

Отношение двух членов тока:

```
|term1| / |term2| ~ c₄/c₂ = l₀²
```

(с точностью до числового множителя порядка единицы, зависящего от нормировки; в решёточной нормировке `c₄/c₂ = l₀²/12`). Словами: **шаг структуры среды `l₀` входит прямо в устройство электромагнитного тока внутри частицы.** Баланс term1 + term2 определяет, как заряд распределён по вихревой трубке, и с ним — радиус трубки. Численно: `r_v = 0.498 · l₀` — плато, устойчивое при вариации анизотропии `K₃/K₁ = 3.5–7.5` и 16-кратной вариации `c₄`. Отсюда цепочка:

```
тождество (6) → структура тока (term1/term2 ~ c₄/c₂) → r_v = l₀/2 → e = π(l₀/2)² → α_bare = 1/128
```

Первая стрелка — эта работа; остальные — [SI-reduction] и [electron-mass]. Цепочка приведена, чтобы показать: вывод Максвелла — не изолированная красивость, а несущий элемент той же конструкции, что даёт `α` и массу электрона.

## 9. Границы, открытые задачи, фальсифицируемость

**Что доказано.** Теоремы 1–2 — математические факты о гладких отображениях в `S²`; их численная верификация — на пределе точности схемы. CP¹-вывод — стандартная процедура с известным обоснованием.

**Что идентифицировано, но не доведено до конца.**

1. **Согласованность `g₀` и `e = π(l₀/2)²` — ✓ проверена 2026-07-02, закрыта частично (§6.2).** Энергетическая нормировка `g₀ = √(μ₀c₄)` единственна; динамический заряд `q_w² = (π/4)·l₀⁴` воспроизводит закон «заряд² ∝ l₀⁴» (структура Гиперболы II подтверждена динамически), `α_w = 1/(32π)` против `α_bare = 1/128` — остался ровно множитель `4/π`. Открыт вывод этого множителя; кандидат на разгадку — различие объектов «квант поля `w`» ↔ «вихревая трубка дефекта».
2. **Верификация на 3D-хопфионе — ✓ выполнена 2026-07-02 на уровне анзаца (скрипт `code/verify_g0_and_identity_3d.py`).** Тождество (6) проверено на каноническом хопфионе (`R_r = 0.641, R_z = 0.807, w = 0.702` [electron-mass]) в полном 3D: невязка `0.595% → 0.204% → 0.130%` на сетках `192³/256³/288³` — падает как `dx⁴` (порядок разностной схемы), то есть чисто дискретизационная; `E_Sk(3D)` совпадает с каноническим 2D-значением до `0.12%`. Впервые численно виден режим term1 ≠ 0: `‖term1‖/‖term2‖ = 0.372` (стабильно по сеткам) — скирмовский вклад в ток включён, как предсказывает §8. Осталось: проверка на full-field релаксации (не анзаце) и количественная связь `term1/term2` с плато `r_v`.
3. **Вывод `c₄` из микроскопики.** Скирмовский коэффициент фиксирован условием `√(c₄/c₂) = l₀` феноменологически; строгий вывод из решёточного гамильтониана среды — открытая задача программы.
4. **Максвелл с размерными коэффициентами.** Полная запись `∇·E = ρ/ε₀` и т.д. с восстановленными единицами SI и сквозной проверкой численных множителей (`½` из (4), `4π` из §6.3) — техническая, но обязательная работа.

**Чем картина фальсифицируется.**

- Обнаружение **магнитного монополя** опровергло бы Теорему 1 (потребовало бы внутреннего пространства размерности выше 2). Редкий случай, когда программа *жёстче* Стандартной Модели: там монополь допустим и даже ожидаем в расширениях, здесь — запрещён.
- **Нецелочисленный** свободный электрический заряд (не кратный дробям конфайнмент-сектора) разрушил бы топологическую интерпретацию §6.3.
- Отклонения от уравнений Максвелла на малых масштабах обязаны иметь **специфическую структуру** (7)/(11) и масштаб `l₀`; нелинейность иной структуры противоречила бы модели.

## Приложение А. Словарик

| Термин | Значение в этой статье |
|---|---|
| **Директор `n`** | Единичный вектор-«стрелка», ориентация точки среды. Термин из физики жидких кристаллов |
| **`S²`** | Поверхность единичной сферы = множество всех направлений трёхмерной стрелки |
| **`ℝ³·¹`** | Пространство-время: 3 пространственные координаты + время |
| **Тождество vs закон** | Тождество верно автоматически, по построению; закон — утверждение о природе, проверяемое опытом |
| **Тождество Бьянки** | Общее имя соотношений вида `∂_[λ F_μν] = 0`, выполняющихся по геометрическим причинам |
| **Правило Лейбница** | Правило дифференцирования произведения: `(fg)' = f'g + fg'` |
| **Смешанное произведение `a·(b×c)`** | Объём параллелепипеда на трёх векторах; ноль ⟺ векторы лежат в одной плоскости |
| **Пулбэк формы площади** | Перенос формы с цели отображения назад на источник; здесь: площадь на сфере направлений, заметаемая стрелкой при сдвиге по паре направлений в пространстве-времени (ориентированная площадь параллелограмма, спроецированная на нормаль `n`) (§3.1) |
| **Гармоническое отображение** | Конфигурация поля, минимизирующая чистую упругую энергию (аналог мыльной плёнки); удовлетворяет `□n = −|∂n|²n` |
| **Инстантон Белавина–Полякова (BP)** | Простейшая точно известная текстура, наматывающая плоскость на сферу один раз; стандартный тестовый объект (§5.4) |
| **Хопфион** | Трёхмерный узел поля `n` — замкнутая закрутка, неустранимая плавной деформацией; кандидат на электрон в программе |
| **Топологический заряд `Q`** | Целое число намоток сферы на сферу; в этой картине = электрический заряд в единицах `e` |
| **CP¹** | Кодировка сферы одним комплексным числом (стереографическая проекция); удобна, но имеет дефектную точку — «полюс карты» |
| **Член Скирма (`c₄`)** | Слагаемое энергии, включающееся при быстрых поворотах поля; не даёт узлу схлопнуться в точку |
| **`l₀`** | Собственный масштаб длины среды, `≈ 0.46 нм`; строится из `{ε₀, μ₀, ℏ}` [SI-reduction] |
| **`α` (постоянная тонкой структуры)** | Безразмерная мера силы электромагнитного взаимодействия, `≈ 1/137`; затравочное значение программы `α_bare = 1/128` |
| **Дальняя зона / ядро** | `r ≫ l₀` (Максвелл точен) / `r ≲ l₀` (доминирует нелинейность, рождается масса). В литературе: ИК- и УФ-режимы |
